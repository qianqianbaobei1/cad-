# 材料拆解工作区

这个目录是从“项目知识库”到“材料采购清单”的中间工作台。

它的定位不是最终采购结果，而是把每一条 BOQ 清单变成可确认、可追溯、可补资料的拆解任务。

## 文件说明

- `materials_master.json`：材料主数据种子，定义标准材料名、采购单位、必填规格和别名。
- `material_aliases.json`：材料别名映射，用来解决“同一种材料多种叫法”的问题。
- `decomposition_rules.json`：清单项到材料项的拆解规则种子。
- `拆解任务队列.json`：每条 BOQ 的拆解任务，包括候选图纸、建议材料、缺失输入和风险。
- `缺失资料清单.json`：系统认为无法自动判断、需要人工补充或确认的问题。
- `可采纳清单_种子.json`：当前置信度较高、资料相对完整的候选项；仍需人工确认后才能进入正式采购清单。
- `待人工确认清单.json`：需要人工确认的任务，是当前阶段最重要的工作清单。
- `材料拆解工作区_人工确认.xlsx`：给业务/造价人员查看和标注用的 Excel 版工作表。
- `manifest.json`：本次生成摘要。

## 当前执行原则

1. BOQ 是数量主线，图纸做法是补充证据。
2. 图纸候选关系不能直接等于最终对应关系，必须可人工确认。
3. 材料名称先进入标准材料主数据，再进入采购清单。
4. 没有完整规格、损耗率、计算规则时，只能进入待确认或缺失资料，不能伪装成准确采购量。
5. 最终采购清单必须能追溯到：BOQ 行、候选图纸做法、材料主数据、计算公式和人工确认记录。

## 下一步应补充的数据

优先补以下几类：

- 材料品牌/型号/规格库。
- 各类材料理论用量和损耗率。
- 地砖、墙砖、吊顶、乳胶漆、栏杆、门窗的企业标准拆解规则。
- 门窗表、材料表、节点详图等补充资料。
- 人工确认字段：采纳/不采纳、确认人、确认时间、确认依据。
