# BOQ 工程量清单 → 采购物料清单 本地执行平台

将建设工程工程量清单（BOQ）自动拆解为采购级物料清单，含材料名标准化、**规格型号提取**、T3物料库匹配、品类归类、定额关联、规范校验。

## 快速开始

```bash
./启动.sh                  # 启动 Web 服务
python3 流水线测试.py      # 命令行交互式拆解
```

浏览器打开 http://127.0.0.1:8765

依赖：Python 3.9+、Flask、pandas、openpyxl（见 `依赖.txt`）
虚拟环境：`.venv/` (Python 3.13, 已安装全部依赖)

## 拆解流水线（v5）

```
输入清单 "010502001 矩形柱 C30 48.6m³"
    │
    ▼
Step 0 [输入解析]: 编码/名称/工程量 + 显式规格提取（C30、HRB400、DN等）
    │
    ▼
Step 1 [AI推理]: 清单项 → 施工工序链（T1知识库做grounding）
    │
    ▼
Step 2 [AI推理]: 工序 → 材料品种推导（T2规则注入prompt，强调规格）
    │
    ▼
Step 2.5 [规格补齐]: ★新增★ KB驱动，不走AI
    ├─ 规格拆分:   从材料名中分离嵌入的规格（"C30混凝土"→材料"混凝土"+规格"C30"）
    ├─ 输入注入:   用户显式声明的规格（C30/HRB400/DN100等）注入到对应材料
    ├─ T3匹配:     读取T3物料库「规格模式JSON」→ 逐参数匹配用户输入值或T3默认值
    └─ 必填检查:   国标要求必填但无取值 → 标记"待确认"，列出允许值供用户选择
    │
    ▼
Step 3 [确定性计算]: 消耗量计算 + 损耗率 + 系数（不走AI）
    │
    ▼
Step 4 [KB校验]: T3标准化 + 品类树损耗率 + N3/N5/N6规范
    │
    ▼
Step 5 [AI评估]: 可信度 + 漏项提示 + 规格完整性审核
    │
    ▼
输出采购物料清单（含规格型号）
```

### 规格提取三重保障

| 优先级 | 来源 | 说明 | 示例 |
|--------|------|------|------|
| 1 | **用户输入** | 从清单描述中正则提取的显式规格，最高优先级 | `C30`→ 混凝土强度等级 |
| 2 | **T3默认值** | T3物料库「规格模式JSON」中定义的默认值，由国标背书 | `牌号=HRB400E`（GB 1499.2-2024） |
| 3 | **待确认** | 国标要求必填但无取值时，列出允许值供人工选择 | `公称直径=?待确认（可选: 6,8,10,12,14,16...）` |

**绝不编造规格值**——三来源之外的值不会出现在输出中。

## API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/breakdown` | 执行清单拆解（返回含规格字段，见下方） |
| GET | `/api/breakdown/:id` | 查询拆解结果 |

### `/api/breakdown` 响应中的规格相关字段

```json
{
  "explicit_specs": {"strength_grade": "C30"},
  "items": [{
    "material_name": "预拌混凝土",
    "spec_hint": "强度等级=C30；坍落度等级=S3",
    "spec_details": [
      {"param": "强度等级", "value": "C30", "source": "输入", "required": true, "standard": "GB/T 14902-2012"},
      {"param": "坍落度等级", "value": "S3", "source": "T3默认", "required": true, "standard": "GB/T 14902-2012"}
    ],
    "missing_required_specs": [],
    "spec_source": "T3标准物料库",
    "name_before_spec_split": ""
  }],
  "items_with_spec": 5,
  "items_missing_required_spec": 0,
  "items_with_t3_spec": 3
}
```

字段说明:
- `spec_hint`: 规格型号展示文本，多个规格用分号分隔
- `spec_details`: 每个规格参数的详细信息（参数名、值、来源、是否必填、国标依据）
- `missing_required_specs`: 必填但无值的规格参数列表，需人工确认
- `spec_source`: 规格数据来源（"T3标准物料库" / "AI推导+输入提取"，含"待确认"标记）
- `name_before_spec_split`: 如果材料名被拆分，保留拆分前的原名
| GET | `/api/kb/t3` | T3物料列表(搜索/分页) |
| GET | `/api/kb/t3/:id` | T3物料详情 |
| GET | `/api/kb/categories` | 品类树节点 |
| GET | `/api/kb/standards` | 规范列表 |
| GET | `/api/kb/quota` | 定额查询 |
| GET | `/api/kb/search?q=` | 全局搜索 |
| GET | `/api/stats` | 知识库统计 |
| GET | `/api/health` | 健康检查 |

## 分类别称来源说明

| 来源标记 | 含义 | 可信度 |
|----------|------|--------|
| `cce` | CCE原始标准数据中的官方别名 | 高 |
| `manual` | 人工确认补充的俗称桥接 | 高 |
| `t3_alias` | T3标准物料库中的别名 | 高 |
| `ai_verified` | AI生成+AI核验通过的别称 | 中 |
| `ai_candidate` | AI生成未经核验的候选 | 中 |
| `ai_candidate_low` | AI生成但置信度低的候选 | 低 |

别称回填流程：CCE标准数据 → AI按分类推理 → AI核验 → 人工审核通过 → 写入分类库
