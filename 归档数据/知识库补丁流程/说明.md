# 三级分类材料库方案

这个目录现在只做一件事：把 CCE JSON 里的第三级/末级分类、分类下标准材料品种、材料别称整理成一个可匹配的标准库。

目标不是固定每个清单必须拆多少材料，而是让 AI 拆出来的任意材料名，都能尽量归到标准三级分类和标准材料品种。

## 数据来源

```text
CCE_Full_Data_1778492694.json
  ├─ category_tree：一级/二级/三级分类树
  └─ data：品种名称、分类ID、分类路径、别名

三级分类材料别称人工补充.csv
  └─ 少量人工确认过的俗称桥接，例如商砼、绑扎丝、耐碱玻纤网格布

三级分类材料别称AI回填.csv
  └─ AI 生成候选并通过 AI 核验后的别称，不直接污染人工补充表
```

## 生成物

```text
数据/三级分类材料库.json
导出/三级分类材料汇总.csv
导出/三级分类材料明细.csv

导出/AI三级分类别称核验结果.csv

```

## 核心结构

```json
{
  "categories": [
    {
      "category_id": "15",
      "category_l1": "黑色及有色金属",
      "category_l2": "建筑钢材",
      "category_l3": "钢筋",
      "category_path": "黑色及有色金属 > 建筑钢材 > 钢筋",
      "material_count": 21,
      "category_aliases": [],
      "materials": [
        {
          "material_name": "三级盘螺",
          "aliases": []
        }
      ]
    }
  ],
  "name_index": {
    "商砼": [
      {
        "material_name": "普通混凝土",
        "category_path": "砼、砂浆及其他配合比材料 > 预拌混凝土 > 普通混凝土",
        "source": "manual"
      }
    ]
  }
}
```

说明：如果一个俗称指向的是末级分类而不是具体品种，例如“商砼/商品混凝土”指向“普通混凝土”这个末级分类，库里会写入 `category_aliases`，匹配时先归到该三级分类。

## 使用方式

生成三级分类材料库：

```bash
.venv/bin/python 知识库补丁流程/脚本/生成三级分类材料库.py
```

按某个三级分类调用 AI 推理别称候选，例如钢筋：

```bash
.venv/bin/python 知识库补丁流程/脚本/AI生成三级分类别称候选.py --分类名称 钢筋
```

核验 AI 候选：

```bash
.venv/bin/python 知识库补丁流程/脚本/AI核验三级分类别称候选.py
```

回填核验通过的别称，并重建材料库：

```bash
.venv/bin/python 知识库补丁流程/脚本/回填AI已核验别称.py
.venv/bin/python 知识库补丁流程/脚本/生成三级分类材料库.py
```

一条命令跑完整流程：

```bash
.venv/bin/python 知识库补丁流程/脚本/运行AI三级分类别称全流程.py --分类名称 钢筋
```

跑全部分类时使用：

```bash
.venv/bin/python 知识库补丁流程/脚本/运行AI三级分类别称全流程.py --全部
```

测试材料归类：

```bash
.venv/bin/python 知识库补丁流程/脚本/匹配材料到三级分类.py --材料 商砼 三级盘螺 绑扎丝 耐碱玻纤网格布 木胶合板模板
```

如果要人工补别称，只改：

```text
知识库补丁流程/数据/三级分类材料别称人工补充.csv
```

然后重新运行生成脚本。

## 后续 AI 使用边界

AI 在清单拆解阶段只做两件事：

1. 尽可能理解清单特征，拆出真实采购材料，数量不固定，能拆多少拆多少；
2. 拆出的材料名进入 `三级分类材料库.json` 做归类匹配。

如果匹配不到：

```text
AI 拆解材料名
  ↓
标准名/别称精确匹配失败
  ↓
包含候选匹配
  ↓
仍失败则标记为“待补别称/待补标准品种”
  ↓
人工确认后写入 三级分类材料别称人工补充.csv
```

不再维护复杂的“AI 全量补全流程”和临时补丁链路。

## AI 回填原则

AI 只做“别称候选”和“候选核验”，不改 CCE 原始标准分类和标准材料名称。

流程是：

```text
CCE 三级分类与标准材料
  ↓
AI 按分类推理 category_aliases / material aliases
  ↓
AI 核验候选是否真实、是否稳定指向目标
  ↓
通过项写入 三级分类材料别称AI回填.csv
  ↓
生成三级分类材料库.json
```

这样拆解阶段输出“盘螺、三级螺、绑扎丝、商砼”这类叫法时，可以先通过别称索引归到标准三级分类，再决定是否需要人工复核。
