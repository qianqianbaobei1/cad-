# 上线步骤（T16 部署前必读）

> 本文是发布清单，不代表已经部署。当前没有目标云平台地址与部署凭证，实际“覆盖部署”需由运维执行。

## 1. 发布前必须确认

| 项 | 要求 |
|---|---|
| 构建号 | 设置 `APP_BUILD_ID`（建议 `v2026.10.18-1`）。未设置时回落到 `backend/config/build_id.txt`，再回落到 git 短提交号 |
| 管理员密码 | **必须**设置 `ADMIN_INITIAL_PASSWORD`（强密码）。生产环境未设置会生成随机密码并只打印一次 |
| 运行环境 | `ENV=production`。否则未登录请求会落到 `default` 租户，且开发环境保留 `admin123` 演示逻辑 |
| 数据目录 | `EXTRACTOR_DATA_DIR` 必须指向持久卷；默认 `/app/backend/data` |
| 上传上限 | `MAX_UPLOAD_MB`（默认 200）按客户最大图纸调整 |
| 模型 Key | 配置 `VISION_*`，或让客户在系统设置里用 BYOK；不配 Key 时识别只能走原生 CAD/PDF 文字 |
| OCR | 镜像已装 `tesseract-ocr` + `tesseract-ocr-chi-sim`；转曲 PDF 框选提表依赖它 |
| TLS | 外部网段必须由反向代理终止 HTTPS；不要把 7860/8000 明文暴露到公网 |

## 2. 数据持久化（最容易踩的坑）

容器内数据在 `/app/backend/data`：

- `extractor.db`（账号、任务、项目、AI 费用、导出历史、预约）
- `price_library.db`（只读价格库，镜像里自带）
- `extractor.db-wal` / `-shm`

如果新平台**不挂持久卷**，每次重启会清空账号、任务和预约。挂卷时注意：把空卷挂到 `/app/backend/data` 会**盖住镜像里的 price_library.db**，必须先把价格库 seed 进卷：

```bash
# 首次部署：先启动一次容器，把镜像内价格库复制到卷
docker run --rm -v /srv/cabinetcore-data:/dest cabinetcore:latest \
  cp /app/backend/data/price_library.db /dest/price_library.db
```

或者不要挂整个 data 目录，改为挂 `extractor.db` 所在目录并把价格库放在只读层（需要改代码路径，当前不推荐）。

## 3. 构建与启动

```bash
# 构建（LibreDWG 0.14 从源码编译，首次较慢）
docker build -t cabinetcore:2026.10.18 .

# 启动
docker run -d --name cabinetcore \
  -p 7860:7860 \
  -e ENV=production \
  -e APP_BUILD_ID=v2026.10.18-1 \
  -e ADMIN_INITIAL_PASSWORD='<强密码>' \
  -e MAX_UPLOAD_MB=200 \
  -e EXTRACTOR_DATA_DIR=/app/backend/data \
  -e VISION_API_KEY='<key>' \
  -e VISION_BASE_URL='<openai-compatible-url>' \
  -e VISION_MODEL='<vision-model>' \
  -v /srv/cabinetcore-data:/app/backend/data \
  cabinetcore:2026.10.18
```

首次启动日志里应出现：

```
[Build] (首次启动) → v2026.10.18-1，已作废旧登录令牌 0 个
```

## 4. 部署后验证（逐项打勾）

1. `GET /api/health` 返回 `{"ok": true, "build_id": "v2026.10.18-1"}`。
2. 用旧浏览器标签的旧 Token 调 `/api/jobs`，必须 **401**，前端回到登录页。
3. 打开首页，`<script src="app.js?v=v2026.10.18-1">`，Network 里 app.js 是新文件（Cache-Control: no-cache）。
4. 用 `ADMIN_INITIAL_PASSWORD` 登录；登录后立即在账号设置里改密码。
5. 上传一张真实 DWG → 识别 → 拆量 → 组价 → 下载拆量清单与组价明细，两份 Excel 能打开且合计一致。
6. 上传一张转曲 PDF → 框选提表 → 能看到文字（若为扫描件，确认 OCR 来源标注）。
7. 预约表单提交一次有效手机号；用平台管理员账号 `GET /api/leads` 能看到；普通企业账号必须 403。
8. 重启容器一次：同 `APP_BUILD_ID` 不应清令牌；改 `APP_BUILD_ID` 再启动应清空全部令牌。

## 5. 回滚

1. 保留上一版镜像 tag。
2. 回滚前先备份数据库：
   ```bash
   sqlite3 /srv/cabinetcore-data/extractor.db ".backup '/srv/cabinetcore-data/backup-$(date +%F-%H%M).db'"
   ```
3. 用上一版镜像与**同一个数据卷**启动；若上一版不兼容新表结构，回滚数据库备份。
4. 回滚后把 `APP_BUILD_ID` 改回上一版，强制所有用户重新登录。

## 6. 已知风险

- SQLite 单机 WAL：只能单写实例；多副本部署需改 PostgreSQL。
- Bearer Token 无绝对过期，只靠构建号轮换；建议下一版加 30 天过期。
- 价库/铜价是“人工基准价”，正式报价前必须按当日行情核实；界面已标注，不要把它宣传成实时行情。
- 锅炉房基准金额已因 T12 价库匹配变化（42,582.05 → 51,059.61），不要把旧金额写进验收脚本。
