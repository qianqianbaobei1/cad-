# 02_图纸布局与箱柜自动定位研究

**分析对象**：利驰图晓晓整图多图框与多箱柜空间自动定位行为  
**数据基准**：现场数据库 `Border` 表 (3 行)、`Cab` 表 (20 行) 实际坐标  
**核心课题**：在单个 `Model` 布局空间平铺的多张图纸中，图晓晓如何自动切分图框、如何发现成套柜列与离散箱体、如何建立空间从属拓扑？

## 二、 配电箱柜的两类典型空间发现模式

在现场抓取的 20 台配电箱柜中，证实系统采用了两种截然不同的空间拓扑切分机制：

```
┌────────────────────────────────────────────────────────────────────────┐
│                        箱柜空间定位的两大核心模式                      │
├───────────────────────────────────┬────────────────────────────────────┤
│ 模式 A：连续拼装成套低压柜列 (GGD) │ 模式 B：离散悬挂式动力/照明箱 (XXM)│
│ (以 C01~C04 集中动力柜为代表)      │ (以 02AP01, JXX1, 02AL01 为代表)   │
│                                   │                                    │
│ ┌─────┬──────────┬──────────────┐ │ ┌────────────┐     ┌────────────┐  │
│ │ C01 │   C02    │     C03      │ │ │   02AP01   │     │    JXX1    │  │
│ │进线 │  喷淋泵  │   动力回路   │ │ │ 配电总箱1  │     │ 检修电源箱 │  │
│ └─────┴──────────┴──────────────┘ │ └────────────┘     └────────────┘  │
│ 特征：共用底基准线，垂直隔板切分  │ 特征：独立封闭外框矩形，顶部居中标题│
└───────────────────────────────────┴────────────────────────────────────┘
```

### 1. 模式 A：成套低压柜列的“基准线共线 + 垂向母线分仓”算法
- **现场坐标实证（C01 ~ C04）**：
  - `C01`: X: `557282 ~ 562841` (宽 5,559)
  - `C02`: X: `562790 ~ 572365` (宽 9,575) &mdash; **起点与 C01 终点相差仅 51 单位，完全无缝紧邻**
  - `C03`: X: `572314 ~ 619322` (宽 47,008) &mdash; **起点与 C02 终点紧邻**
  - `C04`: X: `619271 ~ 621347` (宽 2,076) &mdash; **起点与 C03 终点紧邻**
  - **关键事实**：四台配电柜的底边坐标均为 `Y = 190780.34`，顶边坐标均为 `Y = 208580.34`（柜高恒定为 17,800）。
- **算法规律**：系统通过检测水平贯通的贯穿主母线或底部基础线，结合多条等高的垂直分隔断线，将一整幅低压柜屏台切分为若干个相邻的屏宽仓位。

### 2. 模式 B：离散配电箱的“独立线框 + 居中标题”提取
- **现场实证（02AP01、JXX1、02AL01）**：
  - 箱体四周存在完整封闭的矩形外框（多为细实线或虚线）。
  - 算法直接提取外框的四角极值作为 `CabMinPt` 和 `CabMaxPt`。
  - 箱号箱名提取：在箱体框线顶部或正下方，提取居中对齐的单行文本（如 `02AP01 配电总箱1 GGD`），并使用正则智能拆分出箱号 `02AP01`、名称 `配电总箱1`、柜型 `GGD`。

## 三、 边界异常与空间关联局限性分析（自研规避重点）

在审查 `Cab` 与 `Border` 的外键关联时，发现了一项重大的**底层空间关联缺陷**：

| 异常现象 | 现场实测数据证据 | 底层原因分析 | 自研系统的改进策略 |
| :--- | :--- | :--- | :--- |
| **柜列越界图框误归属** | C01~C04 的实际坐标位于 `X = 557282 ~ 621347`，而“配电系统图一”的起点是 `X = 633187`。在数据库中，C01~C04 却被赋予了图框三的 `Border_ID = '30cd637b'`！ | **图晓晓缺陷**：当图纸左侧的深化柜列未绘制标准图框外边线时，系统缺乏“离散箱柜空间距离判定”，简单将其默认挂靠到了最后激活的活动图框节点下。 | **自研改进**：<br>1. 引入空间拓扑多边形包含判断（`PointInPolygon`）。<br>2. 对落在任何图框之外的箱柜，独立创建“未归属图幅 / 零散系统图”节点，避免跨图框乱挂。 |
| **纯代号无中文箱名** | C01、C03 提取的 `Name` 字段为空字符串，仅有 `Code: C01`。 | 设计院在此类成套柜顶部仅标注了屏台号 `C01`，未在标题处书写汉字名称。 | **自研改进**：自研系统需建立“通过柜内主元件推导用途”机制（如根据 ATS+大互感器自动建议中文名为“双电源进线柜”）。 |
