# 05_多图框多箱柜识别与去重研究

**分析对象**：大型工程单 DWG 文件内多图纸图框切分、多箱柜关联归类与去重机制  
**实证数据库**：`F893CD00A1A27EB6EBDDA72D74762E2F.db` 的 `Border` 与 `Cab` 表  
**设计目标**：解析图晓晓在处理“多图框、多箱柜、同名跨图纸重复箱”时的底层数据结构与逻辑，提出自研去重与归类模型。

## 二、 相同箱柜去重与跨图纸关联机理 (Same-Box / Copy-Box)

在建筑与工业电气施工图中，经常出现“标准层配电箱（如 2F~10F 每层一台 AL1）”、“系统图在一处、平面图在一处”或“多图纸重复索引同个配电箱”的情况。

### 1. 数据库底层设计的实证发现
在 `Cab` 表结构中，图晓晓专门保留了 3 个关键去重与复制标识字段：
- `CabIsSameBox` (布尔型)：标记当前箱柜是否为其他图幅箱柜的“同名箱”。
- `CabIsCopyBox` (整数型)：标记当前箱柜是否由其他箱柜“复制/克隆”而来。
- `CabSameCabIdD` (GUID 字符串)：记录其关联的源主箱柜的 `Cab_ID`。

### 2. 业务去重与工程量折算逻辑
1. **同名箱柜合并规则（Merge Identical Cabs）**：
   - 当用户在全图范围内发现相同代号（如 `02AL01`）在两张图纸中分别出现系统图与控制原理图时，软件允许用户执行【建立同名箱关联】。
   - 此时，其中一台被设为母箱，另一台设为 `CabIsSameBox = True`，并记录 `CabSameCabIdD = 母箱ID`。
   - **BOM 统计效果**：在最终汇总清单中，重复的元器件不进行二次叠加，仅将箱体数量 `Quantity` 累加，避免工程采购虚增翻倍。
2. **倍数箱柜（Multiplier Boxes）**：
   - 若图纸标注 `02AL01~02AL05 配电箱 (共5台)`，系统支持通过单箱识图获得一台的基础清单，在箱柜属性中修改 `Quantity = 5`，系统在导出 BOM 时自动将该箱内所有微断、浪涌等元件工程量乘以 5。

## 三、 自主开发系统的多图框管理架构建议

针对图晓晓在现场暴露的“未标注标准图框外边线的柜列容易发生图框误挂靠”问题，自研系统应采取更稳健的多图框与箱柜拓扑引擎：

```
自研系统空间拓扑判定逻辑：
1. Step 1: 全图扫描闭合外矩形，建立 BorderSpatialIndex (R-Tree 空间索引)。
2. Step 2: 扫描箱柜标题与母线，建立 CabinetSpatialIndex。
3. Step 3: 执行空间包含检测 (Contains):
   - 若 CabinetBox 完全包含在某个 BorderBox 内 -> 明确绑定该 Border_ID；
   - 若 CabinetBox 跨越两个 Border 或完全落在所有 Border 之外:
     -> 严禁随机挂靠！
     -> 自动分配至“默认全局空间 / 自由箱柜集合 (Independent Cabinets)”，在界面以醒目标签提示用户人工确认所属图幅。
4. Step 4: 跨图幅箱号校验:
   - 全图遍历若发现两个箱柜的 `Code` 相同，主动触发“疑似同名箱合并提示”，引导用户一键去重或合并数量。
```
通过上述严谨的空间几何拓扑约束，可 100% 避免跨图框乱挂、元件归属混乱等业界通病。
