# 09_完整产品功能和交互需求

**编制时间**：2026-10-16  
**产品定位**：运行于本地 Windows 环境下的专业配电箱柜 CAD 智能识图、智能扒量与工程组价辅助软件。  
**核心设计哲学**：“极速离线运算、两表一图图文联动、方向手势高效改扒、自学习人机协同”。

## 二、 核心功能规格与交互需求规范

### 1. 两表一图三框双向高亮定位 (核心交互)
- **正向联动**：
  - 用户单击左侧箱柜树的某个箱柜 &rarr; 右侧 CAD 画布瞬间平滑缩放平移至该箱柜范围，箱体以黄色高亮框显示。
  - 用户单击中间表格中的某一行元器件 &rarr; CAD 画布视口中心对准该元器件，其文字与图元外围出现**红色实线高亮矩形框**。
- **反向联动**：
  - 用户在 CAD 画布上双击任意识别标记边框 &rarr; 中间表格自动滚动并高亮选中对应的元器件行；左侧箱柜树自动展开定位到所属箱柜。

### 2. 框选方向手势与快捷改扒（复现图晓晓最高效的交互精髓）
- **Ctrl 热键循环**：
  - 初次按 `Ctrl`：激活【扒箱号】模式。
  - 再次按 `Ctrl`：切换为【扒整箱】模式。
  - 再次按 `Ctrl`：切换为【扒型号】模式。
- **框选方向语义体系**：
  - **从左向右框选 (Left-to-Right)**：
    - 框选中未识别文字：作为分立的独立元器件逐项录入。
    - 框选中已识别文字：触发**快速删除/剔除**，元件从清单中扣除，数量自动减一。
  - **从右向左 / 从下向上框选 (Right-to-Left)**：
    - 框选中多行文字：强制触发**合并扒取 (Merge Pick)**，将多行文字合并为一组复合型号，主型号自动排在最前。
    - 框选包含部分已扒文字：将新文字**追加补充**进已存在的元器件型号中。

### 3. 行内极速编辑与拼音首字母检索
- **需求描述**：当遇到非标冷门型号导致品名识别不准或为空时，预算员无需打开复杂的弹窗。
- **交互动作**：
  - 双击表格中的【元件名称】单元格，原地变为文本编辑框。
  - 输入拼音简写，例如输入 `DLQ`，下拉列表即时筛选出“断路器”、“微型断路器”、“塑壳断路器”供回车快速选定；输入 `HGQ` 快速定位至“电流互感器”。
  - **柜内联动修改**：修改一处元件名称，当前箱柜内与该元件型号完全相同的其余行**全部自动统一联动更正**。

### 4. 同名箱合并与倍数箱柜处理
- **同名箱柜合并**：在左侧树右键点击某箱柜，选择【设为同名箱】，在弹窗中选取母箱编号，系统自动关联 `SameCabId`，避免工程量重复统计。
- **箱柜数量修改**：双击箱柜属性中的【数量】（如将 1 改为 5），系统在汇总导出时自动按倍数展开元器件总工程量。

### 5. 结构化 BOM 报表导出
- **导出格式**：支持导出为 Microsoft Excel (`.xlsx`)。
- **报表结构**：
  - **Sheet 1：按箱柜分类工程量清单**（层级展示：项目 &rarr; 图纸号 &rarr; 箱柜 &rarr; 元件明细）。
  - **Sheet 2：全项目元器件汇总表**（将所有箱柜中的相同型号元件自动累加汇总，便于集中向电气厂商询价采购）。
