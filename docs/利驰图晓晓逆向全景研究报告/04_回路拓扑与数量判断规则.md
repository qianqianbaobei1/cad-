# 04_回路拓扑与数量判断规则

**分析对象**：整图电气回路结构划分、母线相交分析与元器件数量倍乘判定  
**实测依据**：四川中烟项目 20 个配电箱柜、231 个元器件的真实落盘数据与回路特征  
**目的**：提炼出可用于自研系统开发的回路拓扑遍历引擎与数量智能推理规范。

---

## 一、 进线回路与出线分路的几何与拓扑判别准则

在电气原理图（系统图）中，进线回路与出线分路具备明显的拓扑异构性：

| 回路类型 | 空间位置与几何特征 | 包含的特征设备与文字标注 | 拓扑连通流向 |
| :--- | :--- | :--- | :--- |
| **主电源进线回路<br>(Incoming Circuit)** | &bull; 通常位于箱柜最左侧或最顶端。<br>&bull; 导线通常为粗实线或双进线汇合。<br>&bull; 跨越箱体外边界引出至“变压器”或“上一级配电柜”。 | &bull; 双电源转换开关 (ATS)<br>&bull; 大容量塑壳/框架断路器 (400A~630A)<br>&bull; 母线穿芯电流互感器 (大变比，如 500/5)<br>&bull; 进线侧防雷浪涌保护器 (SPD)<br>&bull; 进线总电表/多功能仪表 | 电源从外部引线进入 &rarr; 经过总隔离开关/断路器 &rarr; 汇总注入横贯箱体的水平母线 (Busbar)。 |
| **配电出线分路<br>(Outgoing Branch)** | &bull; 并列密布于水平母线下方。<br>&bull; 多条垂直引线从母线引出，向下引向箱体底部。<br>&bull; 数量通常在 3~30 个回路之间。 | &bull; 微型断路器 (MCB 1P/2P/3P)<br>&bull; 漏电断路器 (RCBO 16A~32A)<br>&bull; 接触器 + 热继电器组合 (电机控制回路)<br>&bull; 分支回路编号 (如 WL1, WP2, WX3) | 从主母线 T 接引出 &rarr; 流经分路开关 &rarr; 穿过出线电缆 &rarr; 连接末端用电设备（照明、水泵、空调）。 |

## 二、 元器件数量智能推理的“三层判定法则”

在工程图纸中，设计院经常采用简图或省略画法。通过对实测 231 条数据的复盘，总结出数量推导的三层法则：

```
                    【元器件数量判定漏斗模型】
                              │
                    ┌─────────▼─────────┐
                    │ 1. 显式文字乘数捕获 │ (权重最高: 100% 遵从)
                    │  匹配 '3x', 'x2'  │
                    └─────────┬─────────┘
                              │ 未匹配到显式乘数
                    ┌─────────▼─────────┐
                    │ 2. 经典回路特征推导 │ (特定上下文: 接触器/互感器)
                    │  星三角启动 -> x3  │
                    └─────────┬─────────┘
                              │ 普通独立元件
                    ┌─────────▼─────────┐
                    │ 3. 几何实体单件计数 │ (基准缺省: Num = 1)
                    │ 每一独立走廊计 1  │
                    └───────────────────┘
```

### 1. 第一层：显式文字乘数捕获（Explicit Multipliers）
- **规则**：利用正则表达式在型号末尾或前方扫描乘数模式：
  - 正则模式：`(?i)(?:[xX\*]\s*(\d+)|(\d+)\s*[xX\*])`
  - **实证**：在 C02 柜第 10 序号元件中，图纸标注为 `3x145A`，系统准确提取数量 `Num = 3`。

### 2. 第二层：经典电气回路特征推导（Implicit Context Rules）
- **规则 A（电动机降压启动回路）**：
  - 当垂直走廊中同时出现断路器、热继电器与接触器时，判定为电机动力回路。
  - 若控制回路图中出现主接触器 (KM1)、星形接触器 (KM2)、角形接触器 (KM3) 三联画法，即使型号仅标写一行 `145A`，数量亦自动推导为 `Num = 3`。
- **规则 B（母线电流互感器三相折算）**：
  - 单线图（Single-line diagram）中，三相交流母线合并画为一根线，穿芯互感器仅画 1 个圆圈。
  - 实测图晓晓按字面统计为 1 只；自研系统应在界面增加“根据三相母线自动展开为 3 支”的快速开关。

### 3. 第三层：基准缺省单件计数（Default Count）
- 凡未命中上述乘数与推导规则的单体元件（如断路器、隔离开关、SPD），只要在垂直走廊内探测到唯一的型号包围盒，默认赋予 `Num = 1`，单位 `台/个/套`。

## 三、 自研系统的回路拓扑遍历实现方案

为了摆脱利驰专有加壳库，自主实现回路拓扑判别的开源算法路线：

```csharp
// 伪代码：基于线段求交图 (Graph) 的回路遍历引擎
public class CircuitTopologyEngine
{
    public List<CircuitBranch> ExtractCircuits(CadDrawing drawing, BoundingBox cabinetBox)
    {
        // 1. 获取箱内所有水平线段 (候选母线) 与垂直线段 (候选引线)
        var horizontalLines = drawing.GetLinesInBox(cabinetBox).Where(l => l.IsHorizontal);
        var verticalLines = drawing.GetLinesInBox(cabinetBox).Where(l => l.IsVertical);

        // 2. 识别主母线：跨度最长且与最多垂线相交的水平线
        var mainBusbar = horizontalLines.OrderByDescending(h => h.Length).FirstOrDefault();

        // 3. 构建相交图：寻找与主母线相交的垂直分支
        var branches = new List<CircuitBranch>();
        foreach (var vLine in verticalLines)
        {
            if (vLine.Intersects(mainBusbar, tolerance: 5.0))
            {
                // 生成垂直走廊包围盒
                var corridorBox = new BoundingBox(vLine.MinX - 1000, vLine.MinY, vLine.MaxX + 1000, vLine.MaxY);
                // 收集走廊内的文字与图元
                var branchTexts = drawing.GetTextsInBox(corridorBox);
                branches.Add(new CircuitBranch(corridorBox, branchTexts));
            }
        }
        return branches;
    }
}
```
通过上述标准几何度量与 R-Tree 空间索引，自研引擎可在 10 毫秒内完成单个复杂动力柜 20 余个回路的拓扑构建与元件归属。
