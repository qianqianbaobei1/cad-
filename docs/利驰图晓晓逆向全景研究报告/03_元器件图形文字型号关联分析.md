**核心核查**：系统到底是如何把 CAD 图纸上的图形符号、零散文字、型号规格与工程数量对应绑定起来的？

## 一、 核心真相核实：控制元件与辅助图例依然 100% 依赖型号文字

在传统工程直觉中，人们常认为“开关可能有型号文字，但按钮、指示灯肯定要靠图形符号去数”。
在对整图中 7 个 `按钮`、7 个 `信号灯` 与 24 个 `熔断器` 进行底层 `TypeNameExt` 原始数据审计后，得出了颠覆直觉的确凿事实：

| 元件名称 (Name) | 提取出的图纸原始文字串 (TypeNameExt 证据) | 实际对应的工业产品标准系列 | 底层识别推导真相 |
| :---: | :--- | :--- | :--- |
| **按钮** | `LA39-11B` | 正泰 / 和泉 LA39 系列标准工业控制平头按钮 | 匹配 `LA39` 按钮前缀，**并非靠识别圆形按钮符号**！ |
| **信号灯** | `AD16-22C` | 工业标准 &Phi;22mm LED 盘面指示灯/信号灯 | 匹配 `AD16-22` 指示灯前缀，**并非靠识别圆圈交叉符号**！ |
| **熔断器** | `50A`、`40A`、`10A` | 配合接触器控制变压器的控制回路保护熔断器 | 在二次回路或隔离刀闸分支捕获单纯安培数判定为熔断器。 |
| **双电源开关** | `ATS-630/630A/4P \| PC级 \| 带检修隔离位` | 双电源自动转换开关系统 | 空间包围盒重叠聚类，将 3 处分散单行文字合并并定型。 |
| **微型漏电断路器** | `iC65N-C16A/1P+Vigi 30mA` (或 `+ELE`) | 施耐德/正泰微断带剩余电流脱扣附件 | 识别到 `+ELE` 或 `+Vigi 30mA` 词条，自动将 MCB 升格为“漏电断路器”。 |

**确定性实证结论**：
图晓晓的整个元器件发现体系，**从主路大开关到二次控制小信号灯，全部贯穿着“工业电气型号规格词典化匹配”的核心逻辑**。图形符号仅作为 CAD 矢量空间的几何锚点与连通线节点，不直接参与元件品类的语义定型。

## 二、 图形、文字与回路的“柱状走廊空间绑定”模型

既然元件定型靠文字，那么系统如何知道这行文字归属于哪个开关图形、哪根母线回路？
通过对 20 个配电箱柜 231 条元件坐标的拓扑分析，还原出图晓晓的**垂直支路走廊绑定模型 (Vertical Column Corridor Model)**：

```
                    【母线 (Busbar / X 跨度)】
════════════════════════════╤════════════════════════════
                            │
              ┌─────────────┴─────────────┐
              │  垂直支路走廊 (Corridor)   │
              │  X_min: 557500            │
              │  X_max: 560200            │
              │                           │
              │   [图形锚点: 开关触头]     │
              │             │             │
              │   [文字聚类包围盒]        │
              │   - ATS-630/630A/4P       │
              │   - PC级                  │
              │   - 带检修隔离位          │
              │             │             │
              │   [电缆消噪过滤]          │
              │   - YJV-4*25 (排除)       │
              └─────────────┬─────────────┘
                            ▼
               输出 Part 记录: 双电源开关
```

1. **垂向走廊生成**：沿水平母线寻找向下垂直引出的出线分支导线（Line）。每根垂线向左右扩展容差公差（例如 $\pm 1000$ 绘图单位），形成一个狭长矩形“走廊”。
2. **走廊内实体投影**：
   - 凡中心点落在该走廊 X 轴区间的单行文字实体（Text/MText），均归属于该回路支路。
   - 过滤掉命中电缆规则（如 `YJV`、`BV`）的文字。
   - 剩余文字按 Y 轴空间间距执行多行聚类，融合成完整型号字符串。
3. **回路编号（LoopID）推导**：
   - 若走廊上方标注有 `WL1`、`1L1`、`WP2` 等回路代号，抽取该代号赋值给该走廊内所有元件的 `LoopID`。

## 三、 自主开发的关键技术设计启发

1. **坚决放弃“纯 CV 图像识别元器件”的不切实际路线**：
   - 在 CAD 矢量图纸中，设计院的开关、按钮画法千奇百怪，训练庞大的 YOLO/ResNet 识别图元不仅极耗显存、推理缓慢，而且一旦遇到非常规图块就产生漏检。
   - **自研系统应当完全复现“高精度矢量文本抽取 + 空间走廊投影 + 国标正则大字典”路线**，以极低的 CPU 消耗换取 95% 以上的高准确率。
2. **多行文本拼接的自适应行间距算法**：
   - 动态计算图纸当前文字的平均字高（`CabAverTextHeight`）。
   - 纵向合并阈值设定为 $1.2 \sim 1.8 \times \text{TextHeight}$；横向对齐偏差容限设定为 $0.5 \times \text{TextLength}$，完美解决跨行、上下错位排版难题。
