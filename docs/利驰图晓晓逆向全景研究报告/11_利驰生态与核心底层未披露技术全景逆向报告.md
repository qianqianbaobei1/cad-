## 二、 逆向发掘的 8 大未披露核心算法与业务机理

通过对官方系统更新日志、底层运行库、模板数据库及配置文件的交叉比对，提炼出图晓晓经过十年工程打磨形成的 8 项核心专用算法：

### 1. “系统同省略设计”识别算法 (Ditto / Same as Above Engine)
- **工程痛点**：在多回路出线柜（如动力配电箱 02AP1）中，电气设计人员为节省绘图时间，在重复出线支路上常标注为 `"同上"`、`"同左"`、`"同 WL1"` 或连续写 `"`"` 符号。
- **算法机理**：
  1. 系统在回路坚向走廊扫描中，若提取到的文本命中省略关键字正则 `^(同上|同左|同前|同WL\d+|")$`；
  2. 算法沿水平母线向左（或垂直走廊向上）寻找最近一个非省略的有效支路；
  3. 克隆该母支路的断路器整机型号、极数、电流及电缆规格，赋值给当前省略支路；
  4. 赋予其独立序号与唯一图元标记（扒图方框标记为青色外框，与常规白色/蓝色外框明确区分）。

### 2. 多行远距离错位标注聚合算法 (Dispersed & Rotated Text Aggregation)
- **工程痛点**：双电源自动转换开关（ATSE）、浪涌保护器（SPD）等复杂元器件的参数往往跨越多个物理层级：
  - 顶端：标注产品系列代号（如 `ATSE-160`）
  - 中部：标注极数与整定（如 `4P 160A`）
  - 底端：标注控制器类型与分断能力（如 `CB级 35kA`）
- **算法机理**：
  - 构建**多槽位语义聚合槽（Multi-Slot Semantic Container）**：
    `[主型号槽]` + `[极数槽]` + `[电流槽]` + `[分断能力槽]` + `[附件槽]`
  - 利用垂直投影走廊的 X 轴容差窗口（$X_{min} - \Delta \sim X_{max} + \Delta$），将同一回路垂直投影范围内的离散文本行吸附进同一槽位；
  - 文本排序权重规则：主型号强制提至最前（`主型号前置优化规则`），规格参数按“极数/电流/分断/附件”标准化重组。

### 3. 元器件型号中数量乘数的消歧义规则库 (Disambiguation Rules for Multipliers)
图晓晓在处理带有 `*` 或 `x` 的字符串时，建立了极为严谨的工业元器件语境规则，彻底解决了通用正则的误判问题：

| 输入原始文本 | 通用正则误判 | 图晓晓工业消歧义输出 | 判定机理与知识库特征 |
| :--- | :---: | :--- | :--- |
| `TMY-40*5` | 5 件 TMY-40 | **铜排 TMY 40x5，数量按长度(米)计** | 命中母线排前缀 `TMY/LMY`，`*` 识别为截面尺寸（宽*厚） |
| `100/5*3` | 15 只 100/5 | **电流互感器 100/5A，数量 3 只** | 命中二次变比 `\d+/\d+` 结构，尾部 `*3` 提取为数量倍率 |
| `10x16Kvar` | 10 台 16kvar | **无功补偿电容器柜 1 套 (10路x16kvar)** | 命中无功容量单位 `kvar/KVAR`，`10x16` 识别为分路容量参数 |
| `PD284I-9X4` | 36 只仪表 | **数显多功能电表 1 只 (型号 PD284I-9X4)** | 识别为仪表开孔/外形系列代号（`-9X4`, `-2X1`），禁止拆分乘数 |
| `20/2/30mA` | 混乱匹配 | **微型漏电断路器 1 只 (20A, 2P, 30mA)** | 三段式解析：20=额定电流，2=极数2P，30mA=剩余动作电流 |
| `Ex9P... x1` + `x2` | 误识别为2件 | **微型断路器 Ex9P...，数量 3 只** | 同一型号下多段数量后缀求和：$1 + 2 = 3$ |

### 4. “改一条，通全柜”相似回路联动扩散算法 (Similar Circuit Propagation)
- **产品逻辑**：在大型动力柜中，往往存在 10~20 条几乎一致的电动机或照明支路。当用户手动框选修正了其中一条支路（如 `BM65-C16A/1Px3`）时：
- **算法行为**：
  1. 系统提取该支路的几何拓扑骨架（开关图元相对位置、下出线走向）；
  2. 提取系列前缀模式（Regex Prefix Pattern，如 `^BM65-`）；
  3. 扫描同柜内所有匹配该拓扑且携带相同前缀的支路；
  4. 批量自动抽取全柜同类回路（如自动提取出 5 个 `BM65-C16A/1P`、6 个 `BM65-C20A/1P`、5 个 `BM65-C25A/1P`），极大降低人工干预成本。

### 5. 箱号、箱名、数量、安装方式四段式非标拆分算法
官方日志展示了大量工业现场非标标题拆分实例，系统采用自然语言分词与工程正则库进行四段式剥离：

- **输入用例 A**：`“屋顶消防风机配电箱 3-RAPEFJ1、2 距地1.5m明装”`
  - **箱名 (Name)**：`屋顶消防风机配电箱`
  - **箱号序列 (Codes)**：`3-RAPEFJ1`、`3-RAPEFJ2`（自动识别顿号与数字序列，**分裂生成 2 台箱**）
  - **数量 (Quantity)**：`2` 台
  - **安装方式 (Mounting)**：`距地1.5m明装`
- **输入用例 B**：`“生活水泵房变频控制柜,设备自带 2AC-SHB1 (共1台)”`
  - **属性识别**：识别出 `设备自带`，打上 `甲供/设备自带` 标签（在后续造价中仅统计一次接口，设备总价计 0 元）。
  - **箱号**：`2AC-SHB1`，数量：`1`。
- **输入用例 C**：`“A地块1AL室外照明配电箱电气系统图(IP65)”`
  - **箱号**：`1AL`
  - **箱名**：`室外照明配电箱`
  - **防护等级**：`IP65`
  - **过滤噪音**：自动剔除尾部干扰词 `“电气系统图”`、`“结线图”`。

### 6. 图框外无归属箱柜的官方挂靠规则
- **历史疑案澄清**：在先前的实测中，我们发现 C01~C04 物理坐标位于图框三左外侧，却被关联至图框三。
- **确凿证据**：利驰在 V6.0.25.0930 更新日志第 21 条白纸黑字写明：  
  > **“21、无图幅范围归属的箱柜，归属于末尾图幅；”**
- **结论**：这证实图晓晓底层并非拥有复杂的图框外几何推导，而是设计了一个“兜底回退规则（Fallback to Last Border）”。
- **我方自主实现优化**：我们在自主方案中设立独立的 `UnassignedLineup`（未挂靠成套柜列组），避免破坏图框的树状归属纯洁性。

### 7. 全图图块自动分解（Block Explode）与签名图元降噪
- **工程难点**：现代工业图纸大量使用匿名块（`*U` 块）和多层嵌套块（Nested BlockReference）。若逐层递归遍历，遍历性能极差且极易陷入循环引用。此外，电子签名（如本项目实测图纸携带的电子签名）包含上万个微小样条曲线（Spline），导致空间 R 树索引构建缓慢甚至崩溃。
- **底层机制**：
  1. 开启图纸时，图晓晓自动调用 ODA 底层在内存虚拟空间执行一次**全图图块分解（Explode Block）**，将嵌套块彻底展平为最原始的 `AcDbLine`、`AcDbPolyline`、`AcDbText`；
  2. 针对电子签名图元（高密度短线段、封闭不规则多边形），按顶点密度阈值执行前置静默剔除（过滤降噪）。

### 8. 自学习知识库补充识别与沉淀机制 (Self-Learning DB)
- **底层实证**：`E:\利驰！\2\LeadOdaAI\LocalData\selflearning.db`，表结构为：
  ```sql
  CREATE TABLE NewPartInfo (
      PartID varchar(20) not null,
      Type varchar(200),
      Name varchar(200),
      Factory varchar(200),
      DwgName varchar(300),
      primary key (PartID)
  );
  ```
- **工作机理**：当系统在图纸中发现无法与内置正则或云端字典匹配的生僻型号时，将其作为未知物料写入 `NewPartInfo`。当用户在 UI 界面手工修正名称与厂家后，系统将该条记录回写并建立映射缓存（`同工程同型号第二次免匹配`），实现“越用越准”。

## 三、 成套组价与工程算量核心模型逆向

图晓晓识图的终点是生成工程清单，进而调用 `SuperWinner/ExWinner` 完成电气成套工程预算。其核心算量模型如下：

### 1. 铜排 / 铝排母线自动算量模型
利驰在 `SuperWinner.dll.config` 中预设了大宗金属基础行情价（铜排基价 56,110 元/吨，铝排基价 16,020 元/吨）：
- **主母线截面选型标准**（根据箱柜主进线额定电流 $I_n$ 自动匹配）：
  - $I_n \le 250\text{A}$：TMY 3*(25x3) + 1*(25x3)
  - $I_n = 400\text{A}$：TMY 3*(40x4) + 1*(30x4)
  - $I_n = 630\text{A}$：TMY 3*(50x5) + 1*(40x4)
  - $I_n = 1000\text{A}$：TMY 3*(80x8) + 1*(50x5)
  - $I_n = 1600\text{A}$：TMY 3*(2x 80x8) + 1*(60x6)
  - $I_n = 2500\text{A}$：TMY 3*(2x 100x10) + 1*(80x8)
- **母线用量与造价推导**：
  $$\text{截面体积} V = \sum (\text{单相截面积} \times \text{柜宽 } W \times \text{相数})$$
  $$\text{母线重量} M = V \times \rho_{Cu} \quad (\rho_{Cu} = 8.9 \times 10^{-3} \, \text{kg/cm}^3)$$
  $$\text{母线材料成本} = M \times \text{铜排市场基价} \times (1 + \text{加工损耗率 } 5\%)$$

### 2. 箱柜壳体表面积定额计算模型
- **非标壳体表面积计算公式**（由图纸提取的尺寸 `W*H*D` 自动驱动）：
  $$S = 2 \times (W \cdot H + W \cdot D + H \cdot D) \quad [\text{m}^2]$$
  $$\text{壳体制作成本} = S \times \text{冷轧钢板/喷涂单价} \ (\text{根据 } \text{CabinetAreaUnitPrice} \text{ 设定})$$

### 3. 一二次辅料与组装人工定额模型
- **一次线辅料**：根据出线微断/塑壳截面，按每回路平均 1.5~2.5 米多股软铜线（BVR）估算；
- **二次线与控制辅料**：每台柜固定包含接地扁铜排（25x4）、阻燃线槽、端子排（UK2.5B）、行线槽及二次控制导线（1.0/1.5 $\text{mm}^2$）；
- **取费规则**：支持“按元器件采购总价百分比（3%~6%）计取”或“按回路定额基数（每回路 30~50 元）计取”。
