# 页面设计：拆量页 与 组价页

> 范围：上传后的两个工作页面。首页（上传 + 任务列表）另见首页评审意见。
> 原则：按人实际干活的顺序设计；**拆量回答"对不对、有多少"，组价回答"多少钱"**，两步分开，各管各的数据。

---

## 0. 全流程与两页的分工

```
首页 ──上传图纸──▶ 识别中 ──▶ ① 拆量页 ──「一键组价」(新标签页)──▶ ② 组价页 ──▶ 导出报价
  └──上传清单Excel───────────────────────────────────────────────▶ ② 组价页
```

| | ① 拆量页 | ② 组价页 |
|---|---|---|
| 谁在用 | 拆量员 / 技术员 | 报价员 / 预算员 |
| 要回答的问题 | 图上有几台柜子、每台里有什么、各多少个 | 每台柜子多少钱、总价多少 |
| 拥有的数据 | 箱柜、元器件、**设计型号**、**数量** | **报价型号（品牌/平替）**、单价、价格来源、费率 |
| 需要看图吗 | 必须，边看边对 | 不需要（偶尔回查） |
| 主按钮 | 一键组价 → | 导出报价 Excel |

**数据归属是两页交互的核心**：数量和设计型号只在拆量页改；价格只在组价页改。组价页想改数量 → 跳回拆量页改，改完同步过来。这样永远不会出现"清单一套、报价一套"。

首页任务状态随之变为：`识别中 → 拆量中 3/8 → 待组价 → 组价中 → 已报价`。

## ① 拆量页

### 1.1 一个拆量员是怎么干活的

1. **先数柜子**：打开图纸，翻目录页 / 配电箱一览表，确认 AI 找到的箱柜数和图上一致，没漏、没多、编号没错。
2. **逐台核对**：一台一台看系统图——进线开关、每条出线回路、柜内其他器件（ATS、互感器、电表、浪涌、接触器、热继）、箱体尺寸和安装方式、同型台数。
3. **改错补漏**：型号抄错的改、漏的补、多的删、归错柜子的挪。
4. **处理存疑**：AI 标出来没把握的地方，逐条看图确认。
5. **核完一台打个勾**，换下一台没核的。中途会被打断，第二天接着干。
6. **全部核完 → 交给组价**。

页面就按这 6 步来。

### 1.3 各区域细节

**A 顶栏**
- 左：`← 我的任务 / 文件名`，返回首页。
- 中：两步进度 `●拆量 ── ○组价`。已经组过价时显示 `●拆量 ── ✓组价`，点"组价"直接切到已打开的组价页。
- 右：`AI 助手`（右侧抽屉）、`导出清单`（不带价格的设备清单 Excel，次要按钮）、**`一键组价 →`（主按钮）**。

**B 进度条** —— 拆量员最关心"还剩多少没干"
- `已核对 3/8` 带进度条，是这页的主指标；点它 = 箱柜栏筛选"未核"。
- `⚠ 待核对 9` 点击 = 筛选有存疑的箱柜。
- `已改 12 处` 点击 = 打开修改记录。
- 箱柜数后面提示数量对账结果，例如 `图纸目录列出 9 台，清单 8 台 ⚠ 可能漏 1 台`（有目录/一览表时才显示）。

**C 图纸栏** —— 只负责看图和定位
- `目录▾`：图纸页下拉，显示页名（"3/20 喷淋泵系统图"），比单纯翻页快得多。
- 缩放 `− 45% + 适应`，拖动平移、滚轮缩放、双击适应。
- `原图`：当前视野按更高清晰度重新渲染（小字看不清时用）。
- `收起`：图纸栏收起，详情栏变宽；箱柜栏顶部出现"显示图纸"。
- 选中箱柜 → 自动翻到所在页并框出整台柜子；选中元器件行或点 `⌖` → 框出那一格（坐标可信时），否则只翻页不画框。
- **反向联动**：在图上框选一块区域 → 右键"识别这块" → 结果作为候选行出现在详情栏，逐条"采用 / 忽略"。用于补漏。

**D 箱柜栏** —— 整份图纸的目录 + 工作进度
- 每行：核对状态（`✓` 已核 / `○` 未核）、箱号、名称、`⚠n` 存疑数、`×3` 同型台数。
- 顶部筛选：全部 / 未核 / 有存疑。
- 第一行"全部汇总 (BOM)"：右栏显示全项目元器件汇总（按名称+型号合并，可看到每种器件分布在哪些柜子）。
- 底部 `＋ 添加箱柜`；每行 `⋯` 菜单：复制箱柜、合并到…、删除。
- 键盘：`↑↓` 切换箱柜；`N` 跳到下一台未核的。

**E 箱柜详情栏** —— 核对和修改都在这里
- **箱柜信息行**：箱号、名称、柜型、尺寸、安装方式、位置、台数，全部是可直接改的输入框（失焦即保存）。台数图上没写时显示 `⚠图上未标台数`。
- **`✓ 标记已核对`**：核完这一台点它，自动跳到下一台未核的。已核的箱柜再被修改时，状态自动退回"未核"并提示。
- 四个页签：
  1. **元器件**（默认）：本页的主产出。列：序号 / 名称 / 设计型号 / 数量 / 单位 / 依据`⌖`。
  2. **回路**：逐条回路（回路号、用途、断路器、接触器/热继/CT、电缆、功率），这是"原始证据"，点行在图上定位。改回路里的断路器型号，元器件汇总同步变化。
  3. **待核对**：本台柜子的存疑项，每条有"看图"`⌖`、"确认无误"、"改为…"三个动作。处理完计数减一。
  4. **修改记录**：本台柜子所有人工 / AI 修改，可单条撤销。
- 表格交互（像 Excel）：
  - 单击选格，方向键移动，回车/双击编辑，Tab 下一格，Esc 取消。
  - `⌘↵` 在下方插入行；`Delete` 删除行；`⌘Z / ⌘⇧Z` 撤销/重做（包括删除、移动、合并）。
  - 可从 Excel 复制多行粘贴进来，按列自动对应。
  - 型号输入时自动补全（来自器件库），统一写法。
- 行尾 `⋯` 菜单：拆成两行、复制一行、移到其他箱柜…、在图纸中查看、删除。
- 多选（Shift/⌘ 点击）右键：合并为一行（数量相加）、批量改数量、批量移动、删除。
- **改过的格子**左上角有色角 `◤`，悬停显示"原识别值：90~110A，你于 14:32 修改"，可一键还原。
- **校验**（标黄提示，不拦截）：数量非正数；"只/台"类单位出现小数；同一柜内两行完全相同（提示合并）；断路器型号里没有电流值。

### 1.4 一键组价（两页的交接）

点 `一键组价 →`：

1. **检查**：弹一个确认框，把没干完的事摆出来，但不强拦：
   ```
   准备组价：8 个箱柜 / 10 台 / 186 件元器件
   ⚠ 还有 5 台未标记核对，9 处待核对未处理
   [回去继续核对]   [仍然组价 →]
   ```
   全部核完时不弹框，直接进入下一步。
2. **生成清单版本**：把当前清单固化为"清单 v1"（快照），组价基于这个版本计算。
3. **新标签页打开组价页**：`#/price/<任务号>`。拆量页保持打开，两页可以并排放。
4. 首页任务状态变为"组价中"。

再次点击时：已有组价页 → 直接切过去；如果清单在那之后改过，组价页会出现同步提示（见 2.5）。

## ② 组价页

### 2.1 一个报价员是怎么干活的

1. **定口径**：这单按什么品牌报（设计指定还是平替）、铜价按多少、取哪档费率、利润和税率多少、要不要下浮。
2. **自动套价**：系统按型号去价格库匹配单价。
3. **补缺价**：匹配不到的逐个询价、填价；有些按经验价、历史报价填。
4. **核箱体和辅材**：箱体按尺寸/钣金定额算、母排按铜价算、人工按费率算，看看合不合理。
5. **看总价、调利润**：总价跟预期比，调利润率或下浮。
6. **出报价单**：导出 Excel；可能出好几版（不同品牌、不同利润）给老板或客户比较。

### 2.3 各区域细节

**A 顶栏**
- 两步进度 `✓拆量 ── ●组价`：点"拆量"切回（或打开）拆量页。
- **报价版本 `v1 正泰平替 ▾`**：一份清单可以出多版报价（按设计品牌 / 正泰平替 / 利润 6% 版…）。下拉里可"另存为新版本"、"对比两个版本"（并排显示每台柜子的价差和总价差）。
- 主按钮 `导出报价 Excel`：导出当前版本，结构与表格一致（汇总表 + 明细表 + 价格构成 + 缺价/手填清单 + 变更记录）。

**B 组价口径** —— 报价员第一件事
- 品牌：`按设计`（报价型号 = 设计型号）或指定平替品牌；高级：按器件类别分别指定品牌（断路器正泰、接触器施耐德）。
- 铜价、人工费率档、利润率、税率、下浮率。
- 改了任何口径 → `重新计算` 按钮亮起；点击后全表重算。手填的单价**不被覆盖**（报价员填的询价不能被冲掉）。

**C 价格构成条** —— 一眼看到钱从哪来
- `元器件 + 箱体 + 辅材 + 人工 = 成本 · 利润 · 税 → 报价合计`，合计最醒目。
- `⚠ 缺价 3 项` 点击 = 打开"仅看缺价"并跳到第一项；`✎ 手填 4 项` 点击 = 只看手填的。
- 表格工具：全部展开 / 全部收起 / 仅看缺价 / 搜索（箱号、型号）。

**D 大表** —— 树形表格，箱柜是父行，元器件是子行
- **箱柜行**（加粗、浅底色）：箱号、名称、安装位置、柜型尺寸、台数、**单台价**、**合价 = 单台价 × 台数**。收起所有箱柜时，这张表就是报价汇总表。
- **元器件行**（缩进，序号 2.1、2.2）：名称、设计型号、报价型号、数量、单位、**单价**、**合价**、**来源**。
- **构成行**（每台柜子展开后的末尾，灰色）：元器件小计、箱体、母排辅材、安装调试。四行相加 = 箱柜行的单台价。
- **设计型号 vs 报价型号分两列**：设计型号来自拆量页（只读）；报价型号是这一版报价实际报的产品（平替后的品牌型号）。客户问"你报的是什么"时一目了然。
- **价格来源**：

  | 来源 | 含义 | 样式 |
  |---|---|---|
  | 价库 | 按品牌+型号自动匹配 | 普通 |
  | 手填 | 报价员填写/改过（询价、经验价） | 蓝色 `✎`，悬停显示原价、修改人、时间、备注 |
  | 历史 | 采用了过往报价中同型号的价格 | 灰蓝，悬停显示出自哪个项目、哪天 |
  | ⚠缺价 | 没匹配到 | 橙色，单价格留空待填 |
  | 定额 / 铜价 / 费率 | 箱体、辅材、人工按规则算出 | 灰色，悬停显示计算公式 |

- **哪些能改**：
  - 能改：报价型号（换型）、单价、来源备注；箱体/辅材/人工这几行的金额（改了即变"手填"）。
  - **不能改**：数量、设计型号、箱柜、台数——它们属于拆量。双击时提示"数量在拆量页修改 → [去拆量页]"，点击后拆量页定位到这一行。
  - 合价、小计、合计永远是算出来的，浅灰底。
- Excel 式操作：冻结表头、冻结前两列（序号、箱号）、冻结合计行；方向键移动、回车编辑、Tab 下一格；⌘C/⌘V（可从询价表整列粘贴单价）；列宽可拖并记住。
- 多选右键：批量换品牌、批量设单价、批量标记"已询价"。

**F 价格候选面板**（选中某个元器件的单价格时，从右侧滑出，不挡表格）
```
热继电器 90~130A  × 2 只
─────────────────────────
价库匹配
  正泰 NR2-150 90~150A   ¥298   [采用]
  德力西 JRS1D-150      ¥276   [采用]
历史报价
  鼎鑫大厦 2026-09  ¥310        [采用]
─────────────────────────
手填单价 [       ] 备注[询价：xx电气 王工]  [确定]
```
- 这就是报价员找价的过程：先看库里有没有，再看以前报过多少，都没有就询价后手填。
- 采用后自动带出报价型号、单价和来源。

**E 状态栏**
- 当前选中格；基于的清单版本（"清单 v1，拆量页 14:20 版本"）；最后计算时间；未保存修改数。

### 2.4 组价页的处理顺序引导
- 首次打开时自动展开"有缺价的箱柜"，其余收起；第一个缺价格自动选中，右侧打开价格候选面板。
- 填完一个缺价按 `Enter` 自动跳到下一个缺价格——像在 Excel 里往下填一列。
- 缺价全部补完时，构成条上的 `⚠ 缺价` 变为 `✓ 价格齐全`。

### 2.5 两页之间的同步（拆量改了，组价怎么办）
拆量页在"清单 v1"之后又改了东西（比如补了一个元器件、改了数量）：

```
┌──────────────────────────────────────────────────────────────────────────┐
│ ⓘ 拆量清单已更新：新增 2 项、数量变化 3 项、删除 1 项   [查看变化] [同步到报价] │
└──────────────────────────────────────────────────────────────────────────┘
```
- 组价页顶部出现这条提示，不自动改报价（报价员可能正在填价）。
- `查看变化`：在表中标出新增（绿）、数量变化（黄）、删除（删除线）的行。
- `同步到报价`：合并进来——已填的单价和手填记录保留；新增项去价库匹配，匹配不到即"缺价"；被删的行移除。清单版本号变为 v2。

### 2.6 上传 Excel 清单直接组价
- 首页拖入清单 Excel → 解析完直接进组价页，顶栏进度显示 `✓清单导入 ── ●组价`，没有拆量页可跳（"去拆量页修改"改为在组价页内直接编辑数量）。
- 导入有问题的行，在顶部提示"有 4 行没能识别，已跳过 [查看]"，可在这里补录。
- 提供"下载清单模板"（首页上传区有链接）。

## 3. 两页共用的约定

- **AI 助手**：两页都有，右侧抽屉。拆量页问"C02 里有哪些器件 / 把所有 C16 微断改成 C20"；组价页问"换成正泰能省多少 / 哪几台柜子最贵"。AI 做的修改和人改的一样：带修改标记、进修改记录、可撤销。
- **修改记录**：谁、何时、原值 → 新值、原因；拆量和组价各自记录，导出时附在 Excel 里。
- **自动保存**：每次修改即保存，状态栏显示"已保存 14:32"；不设"保存"按钮。
- **多人同时编辑**：保存时发现别人已改过 → 提示"已被 张工 修改，[刷新查看]"，不静默覆盖。
- **重新识别保护**：拆量页有人工修改时点"重新识别"，先提示"有 23 处人工修改"，让用户选"保留修改并合并 / 全部覆盖"。
- **尺寸调整**：分栏可拖动、双击复原、宽度记住；图纸栏可收起；窄屏改上下排列。
