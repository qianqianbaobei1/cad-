# 后端与安全审查（2026-10-18）

> 范围：FastAPI 路由鉴权、多租户隔离、上传/下载、路径穿越、外部进程、令牌、默认口令、限流、部署。
> 方法：路由逐条静态核对 + 关键接口实测 + 全量 pytest。**不是渗透测试**，没有做 fuzz/依赖 CVE 扫描。

## 核查通过（保持现状）

- **Token 解析**：统一从 `Authorization: Bearer` / `x-token` / 查询参数读取；失效 Token 标记 `invalid_token`，生产环境强制降级 guest，不信任客户端 `x-tenant-id`。
- **任务级租户隔离**：`/api/jobs/{id}` 系列全部 `_validate_job_id` + `check_job_tenant_access`；`/api/jobs` 列表按当前租户过滤。
- **项目隔离**：`db_list_projects / db_ensure_project / db_update_project / db_rename_project / db_get_ai_logs` 全部带 `tenant_id`；项目改名同时改 jobs/ai_logs/export_history，避免孤儿数据。
- **路径穿越**：job_id 限制 `[A-Za-z0-9_-]{1,64}`；裁切图文件名限制 `^[A-Za-z0-9_-]+\.png$` 且必须以 `{job_id}_crop_` 开头；上传文件名不直接拼路径（用 job_id + 扩展名）。
- **鉴权入口**：`/api/admin/accounts` 仅 admin；企业管理员只能看本企业；`/api/settings` 公开字段不含 Key，只回传“是否已配置”。
- **导出/下载**：`/api/jobs/{id}/excel` 与 `bom` 都经过 `check_job_tenant_access`。
- **外部进程**：dwg2dxf/LibreDWG、tesseract 均带超时；PDF 框选 OCR 超时 180s；未把用户输入拼接进 shell。
- **数据落盘**：SQLite WAL + 原子 JSON 镜像；任务状态实时保存，重启可恢复为 interrupted。

## 仍建议做（上线前非阻断）

| # | 严重度 | 问题 | 建议 |
|---|---|---|---|
| 1 | P1 | Bearer Token 没有过期时间，只靠换构建号清空 | 增加 30 天绝对过期 + 滑动续期；或加“退出所有设备” |
| 2 | P1 | 没有按租户/用户的 AI 费用上限 | 给 `/api/jobs/{id}/chat`、`ai_review`、识别调用加日/月配额，防成本滥用 |
| 3 | P1 | 没有 HTTPS/HSTS 配置 | 外部网段必须由反向代理终止 TLS；只在内网可接受 HTTP |
| 4 | P2 | 上传只按扩展名判断类型 | 增加文件头魔数校验（PDF `%PDF`、DWG `AC10`），降低伪装文件风险 |
| 5 | P2 | SQLite 单机 WAL | 多实例部署会争锁；外部产品若多副本，需换 PostgreSQL 或单写实例 |
| 6 | P2 | 日志含手机号、项目名 | 生产日志做脱敏与保留期；预约手机号属于个人信息 |
| 7 | P2 | 依赖 CVE 未扫描 | 上线前跑 `pip-audit`/`npm audit`（当前无前端依赖包管理，主要查 Python） |
