# 验收意见：报价字段与组价口径

> 依据：客户正式报价单《摩尔报价（授权）-四川中烟工业有限责任公司成都卷烟厂制丝线升级改造项目.xlsx》
> 结构：封面 / 屏柜汇总表（164 台，合计 ¥826,288.83）/ 屏柜分项表（每台柜子一个明细块）

---

## 一、从报价单读出来的事实

### 1. 每台柜子的明细块长这样

```
1-6 │ 柜号：01LBZ1 │ 型号：GGD(落地) │ 名称：照明配电总箱 │ 制丝工房
序号 │ 元件名称   │ 型号规格                 │ 单位 │ 数量 │ 单价     │ 总价     │ 生产厂家   │ 备注
 1   │ 塑壳断路器 │ CVS160B ETS2.2 3P 125A   │ 只   │  1   │ 1124.08  │ 1124.08  │ 施耐德电气 │
 2   │ 多功能表   │ 带通讯接口                │ 只   │ 11   │  155.00  │ 1705.00  │ 国优       │
 …
 9   │ 铜材       │                          │ 套   │  1   │ 1447.94  │ 1447.94  │            │
10   │ 壳体       │                          │ 台   │  1   │ 1428.00  │ 1428.00  │            │
11   │ 小计       │                          │      │      │          │ 11483.86 │
12   │ 辅料       │                          │      │      │          │   574.19 │   ← 小计 × 5%
13   │ 成套制作费 │                          │      │      │          │  1085.22 │   ← (小计+辅料) × 9%
14   │ 税费       │                          │      │      │          │   788.60 │   ← (小计+辅料+制作费) × 6%
15   │ 单台合计   │ 13931.87
总计 │ 台 │ 1 │ 13931.87                                                         ← 单台合计 × 台数
```

### 2. 几个关键规律
- **费用是一条链**：辅料 5% → 成套制作费 9% → 税费 6%，逐级叠加（全部明细块验证一致）。
- **壳体、铜材是普通明细行**：单位“台 / 套”，和元器件同列，不是单独的构成区。
- **“报价不含”**：101 行写在“生产厂家”列、单价 0——这些器件**照样列出来**，只是不计价（如故障电弧探测器、智能照明模块）。
- **型号规格是报价型号**：如 `C9 2P D20A 6kA+ELE 30mA` 已经是施耐德的具体型号；图纸上通常只写“2P D20A 30mA”。
- **生产厂家**：施耐德电气 677 行、德力西 125、施耐德万高 30、国优 23；405 行留空（二次元件、互感器、壳体、铜材等）。
- **单位**只有三种：只 / 台 / 套。
- **汇总表**每台一行：序号、柜号、箱柜名称、箱柜型号、单位、数量、单价、总价、备注（=安装区域：锅炉房 / 制丝工房）。
- **分类分组**：汇总表按“配电箱”“配电柜”等分组，序号写成 `1-1、1-2…`（组号-序号）。
- **总计取整到元**：汇总表“合计”826,288.83，“总计”826,289，大写“捌拾贰万陆仟贰佰捌拾玖元整”。
- **项目级信息**：项目单位、项目名称、联系人、电话、金额单位、报价日期、文件编号；总计台数、总计金额、**大写金额**；报价说明（“报价含 13% 税和运费；不含故障电弧、消防电源监控”）；报价人、审核人。

## 二、字段：拆量要什么，组价加什么

### 箱柜（每台柜子）

| 字段 | 报价单位置 | 拆量 | 组价 | 说明 |
|---|---|:-:|:-:|---|
| 分类 | 汇总表“配电箱/配电柜”分组 | ✔ | ✔ | 决定序号的组号 |
| 序号 | 1-1、1-6 | 自动 | 自动 | 组号-顺序号 |
| 柜号 | 01LBZ1 | ✔ | 只读 | |
| 箱柜名称 | 照明配电总箱 | ✔ | 只读 | |
| 箱柜型号 / 安装方式 | GGD(落地) | ✔ | 只读 | 图纸上的柜型+安装 |
| 外形尺寸 | （报价单未列，壳体计价要用） | ✔ | 只读 | 壳体价格的依据 |
| 安装区域 | 锅炉房 / 制丝工房 | ✔ | 只读 | 汇总表“备注”列 |
| 台数 | 数量 | ✔ | 只读 | |
| 小计 / 辅料 / 成套制作费 / 税费 | 明细块底部 | — | ✔ 自动算 | 费率链 |
| 单台合计 | 明细块 | — | ✔ 自动算 | |
| 总价 | 单台合计 × 台数 | — | ✔ 自动算 | |

### 元器件（每一行）

| 字段 | 报价单列 | 拆量 | 组价 | 说明 |
|---|---|:-:|:-:|---|
| 序号 | 序号 | 自动 | 自动 | |
| 元件名称 | 元件名称 | ✔ | 只读 | 塑壳断路器、电流互感器… |
| 设计规格 | （图纸原文） | ✔ | 只读 | 图上抄下来的规格：`2P D20A 30mA`、`150/5` |
| 报价型号规格 | 型号规格 | — | ✔ | 选品牌后的具体型号：`C9 2P D20A 6kA+ELE 30mA`。导出时就是报价单的“型号规格”列 |
| 单位 | 单位 | ✔ | 只读 | 只 / 台 / 套 |
| 数量 | 数量 | ✔ | 只读 | |
| 生产厂家 | 生产厂家 | 可选（图纸指定品牌时记录） | ✔ | |
| 单价 | 单价 | — | ✔ | |
| 总价 | 总价 | — | ✔ 自动算 | 单价 × 数量 |
| 价格来源 | （内部，不导出） | — | ✔ | 信息价 / 市场价 / 本地价 / AI 建议价 / 历史价 / 手填 |
| 是否计价 | “报价不含” | ✔ 可预标 | ✔ | 不计价的行照样列出，单价记 0，厂家列导出为“报价不含” |
| 备注 | 备注 | ✔ | ✔ | |
| 依据 / 核对状态 | （内部，不导出） | ✔ | — | 拆量专用：图纸定位、已核/存疑 |

**壳体、铜材**：拆量时作为两行固定项自动生成（壳体按尺寸，铜材按回路/母排），数量可改；组价时和元器件一样定价。

### 项目（整份报价）

| 字段 | 拆量 | 组价 |
|---|:-:|:-:|
| 项目名称、项目单位 | ✔（可从图签带出） | ✔ |
| 联系人、电话 | — | ✔ |
| 报价日期、文件编号 | — | ✔ 自动生成，可改 |
| 金额单位 | — | 固定“人民币元” |
| 总计台数、合计金额、总计金额（取整到元）、大写金额 | 台数 | ✔ 自动算 |
| 报价说明（含税/运费、不含项） | — | ✔ 可编辑，默认根据“不计价”行自动生成“不含 xx” |
| 报价人、审核人 | — | ✔ |

**一句话**：拆量只回答“有哪些、多少个、在哪台柜子”；组价在此基础上加“用哪家、什么型号、多少钱、怎么算的”。

## 三、组价页顶部：改成一句话的“富文本”，不用小输入框

### 问题
现在顶部是一排小输入框（品牌、铜价、人工、利润、税率…），标签被挤成竖排，读不顺，也和报价单的口径对不上。

### 改法：一句可读的话，下划线的词可以点开修改

```
本报价按  施耐德电气 ▾  报价，价格取  市场价 ▾ ，辅料  5% ，成套制作费  9% ，税费  6% 。
共 164 台，合计 ¥826,288.83，报价总计 ¥826,289（捌拾贰万陆仟贰佰捌拾玖元整）   ⚠ 缺价 12 项 · 不计价 101 项
```

- 读起来就是一句报价口径，没有框，不挤；**下划线的值点一下弹出小菜单/小输入**，改完整句即时重算。
- 第一句是**三个口径**，按报价员的思考顺序：
  1. **品牌**：施耐德电气 / 德力西电气 / 正泰 / 按设计指定 / 混合（按器件类别分别指定，点开后是一张小表：断路器→施耐德、电涌保护器→德力西…）。
  2. **价格来源**：信息价 / 市场价 / 本地价 / AI 建议价 / 历史价。这是“默认用哪种价”；单行可以单独换来源（在价格候选面板里）。
  3. **费率链**：辅料 5%、成套制作费 9%、税费 6%——和客户报价单的计算方式一一对应。
- 第二句是**结果**：台数、总计金额、大写金额，以及需要处理的事（缺价、不计价）。点“缺价 12 项”直接筛选。
- 铜价、人工等次要参数不放在这句话里；它们影响的是“铜材”“壳体”这类行的价格，放在这些行的价格候选面板里调。

## 四、对两页的具体修改

### 拆量页（扒图页）元器件表

列改为与报价单对齐（不含价格）：

| 序号 | 元件名称 | 设计规格 | 单位 | 数量 | 指定厂家 | 计价 | 备注 | 依据 | 状态 |
|---|---|---|---|---|---|---|---|---|---|

- 新增 **单位**只允许 只 / 台 / 套。
- 新增 **计价**列：默认 ✔；取消勾选 = 报价不含（灰色显示，仍保留）。例如图上写“由厂家配套”的器件。
- 表格末尾自动带两行：**壳体**（按尺寸）、**铜材**；可改数量、可删除。
- 箱柜头部补齐：分类、柜号、名称、柜型 / 安装、尺寸、安装区域、台数。

### 组价页大表

箱柜行和明细行的列对齐报价单：

| 序号 | 柜号 | 元件名称 | 设计规格 | 报价型号规格 | 单位 | 数量 | 单价 | 总价 | 生产厂家 | 来源 | 备注 |
|---|---|---|---|---|---|---|---|---|---|---|---|

- **箱柜行**：序号 `1-6`、柜号、名称、柜型、台数、单台合计、总价；展开后是明细。
- **明细末尾的构成行**改为报价单的五行：**小计 / 辅料 / 成套制作费 / 税费 / 单台合计**（原来的“箱体 / 母排辅材 / 装配人工”三行去掉——壳体、铜材已经是明细行，人工即“成套制作费”）。
- **不计价行**：灰色，单价 0，厂家列显示“报价不含”。
- **来源**列只在页面上显示，不导出。
- 价格候选面板按价格来源分组：信息价 / 市场价 / 本地价 / AI 建议价 / 历史价 / 手填。

### 导出 Excel
直接按客户这份报价单的版式输出三张表：**封面**、**屏柜汇总表**、**屏柜分项表**——字段、顺序、序号格式（1-1）、费率五行、总计与大写金额、报价说明、报价人/审核人都对齐。内部字段（设计规格、价格来源、依据、核对状态）不导出。

## 五、验收清单
- [ ] 组价页顶部是一句可读的口径，没有成排的小输入框
- [ ] 口径三项：品牌、价格来源（信息价/市场价/本地价/AI 建议价/历史价）、费率链（辅料/成套制作费/税费）
- [ ] 明细末尾构成行为：小计 / 辅料 / 成套制作费 / 税费 / 单台合计，计算结果与客户报价单一致
- [ ] 壳体、铜材作为明细行出现
- [ ] 支持“报价不含”：照常列出、单价 0、厂家列显示“报价不含”
- [ ] 拆量页不出现任何价格字段；组价页的数量、规格只读
- [ ] 合计保留两位小数，总计取整到元，大写金额与总计一致
- [ ] 汇总表序号为“组号-序号”，备注为安装区域
- [ ] 导出 Excel 与客户报价单版式一致，含大写金额、报价说明、报价人/审核人
