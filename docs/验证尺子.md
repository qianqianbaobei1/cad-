# 配电箱识图验证尺子

功能做没做对，只看这把尺子，不看程序上一次自己打出来的结果。

## 怎么算对

一张图先有金标准，再跑提取，然后打三项分。三项的召回和精确率都是 1，这张图才算通过。

| 项目 | 量什么 | 算错的情况 |
|---|---|---|
| 识别 | 箱号集合 | 漏箱、多箱、箱号写错 |
| 切分 | 每条回路落在哪个箱 | 回路进了别的箱，或无编号备用回路串到别的箱 |
| 提取 | 对上的那一行 | 相序、断路器、回路号、电缆、负荷名称、功率，以及箱体名称、防护等级、安装、位置、尺寸、台数，有一格和金标准不一致 |

比对前去掉空白、统一大小写，直径符号 `×` 与 `x` 视为相同。功率按数值比，`1` 与 `1.0` 相同。备用回路图上没有回路号，按该箱内未编号行的先后顺序对齐。

多出来的回路、少掉的回路，都让精确率或召回率低于 1。待核对不能拿来顶替缺失的格子。

计算参数（Pe、Kx、Pjs、cosφ、Ijs）抄在金标准里备查。当前清单没有这些字段，不计入通过线。

## 金标准从哪来

金标准是对着图纸逐格抄的。文字层、模型输出、上一次 Excel 都不能反过来充当金标准。图纸若改过，先改金标准并写明原因，再重新打分。
