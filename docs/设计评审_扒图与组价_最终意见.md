# 设计评审最终意见：扒图页 · 组价页

> 评审对象：`Downloads/扒图/`、`Downloads/组价/`（screen.png + code.html；DESIGN.md 为通用设计规范，无需修改）
> 结论：两页结构正确，**保留 Excel 外观**；本轮只做“去噪、对齐、统一”，不改流程。

---

## 一、三条总原则

1. **Excel 外观保留，内容给人看。** 网格线、灰色表头带、行号列、列字母、fx 栏、底部页签都保留；但里面不再出现假公式、重复说明、机器语言。
2. **正常的不标，只标异常。** 正常行的状态/来源格留空；只有 改过 / 存疑 / 缺价 / 手填 才出标记。
3. **一格一行，绝不竖排、绝不折行。** 所有行统一行高；放不下就加宽列、缩写，或收进悬停提示。

## 二、两页通用修改

| # | 问题 | 修改 |
|---|---|---|
| 1 | 扒图页深色顶栏 + 深色图纸画布，组价页浅色，两页风格不一 | 统一浅色。图纸画布用白底（与真实图纸一致） |
| 2 | 步骤命名不一：“拆量核对—组价套定额(待联动)” / “拆量完成—组价核算” | 统一为 **拆量 — 组价**，删“(待联动)” |
| 3 | 产品名不一 | 统一为“配电箱识别组价系统”（或定一个，全站一致） |
| 4 | 装饰性文字：`CAD-2024` 标签、`X:1240 Y:880` 坐标、“图纸坐标已锁定·反向寻迹高亮”、AI 助手绿点 | 全部删除 |
| 5 | 文字被挤成竖排（“箱号:”“✓已核”“人工整定”“品牌:”“铜基准”“利润”等） | 必须一行显示；列宽按内容给足 |
| 6 | 表格行高不一（名称折成 3~4 行把行撑高） | 统一行高 32px；名称、型号单行，超长省略 + 悬停显示全文 |
| 7 | fx 栏显示假公式（`=C02.元器件清单[...]`、`=PRICE_LOOKUP(...)`） | 保留 fx 栏位置与样式，内容改为人话：`单元格 │ 箱柜 · 元器件 · 字段 · 来源` |
| 8 | 单元格里写公式文本（`=COUNTA(B1:B8)`、`=SUM(D1:D8)`） | 格子只显示结果；公式说明只在选中该格时出现在 fx 栏 |
| 9 | 底部页签文字折行 | 单行短名称，见各页 |
| 10 | 空白行无作用 | 保留 2~3 行，在空白行直接输入 = 新增一行 |

**Excel 外观规范（两页表格统一）**
- 网格线：1px `#E2E8F0`；表头带：`#F1F5F9`，列字母一行 + 中文列名一行，两行都不折行
- 行号列：左侧窄列，灰字
- 数字：右对齐、等宽字体、千分位、金额统一 2 位小数
- 选中：2px 蓝色单元格框；所在行号、列字母高亮
- 冻结：表头 + 前两列（行号、序号/箱号）+ 合计行
- 状态栏：左侧选中信息，右侧 计数 / 求和（删“平均值”）

## 三、扒图页（拆量）

### 保留
- 顶部统计条：箱柜 / 元器件 / 回路 / 已核对进度条 / 待核对 / 已改，以及“图纸目录 9 台，清单 8 台，可能漏 1 台”
- 箱柜栏：全部 / 未核 / 存疑 筛选；每行状态；“＋ 添加箱柜”
- 「定位图纸」「✓ 标记已核对」
- 改值痕迹“原：90~110A”

### 修改

| 区域 | 现在 | 改为 |
|---|---|---|
| 顶栏 | 标题旁 `CAD-2024` | 删除 |
| 图纸画布 | 深色背景；高亮框标签带坐标 | 白底；高亮框标签只写“C02” |
| 图纸工具栏 | 目录 / ‹› / −45%+ / 适应 / 原图 / 收起 | 保留；“原图”改名“高清” |
| 图纸栏底部 | “图纸坐标已锁定 · …反向寻迹高亮” | 删除 |
| 箱柜栏状态列 | “✓已核”两行竖排 | 单字符图标：✓（绿）/ ○（灰）/ ⚠n（橙） |
| 详情头部 | “箱号: 名称: 柜型: 尺寸:”标签 + 输入框挤一行 | 第一行：**C02 喷淋泵控制柜**　[定位图纸] [✓ 标记已核对]；第二行灰字：GGD · 800×2200×600 · 落地 · 泵房配电间 · 1 台（点击某项就地编辑） |
| 表头 | `B (元器件名称)` `C (设计型号 – 图纸抄录)` `G (核验状态)` | 两行表头：上行 A B C D E F；下行 名称 / 型号规格 / 数量 / 单位 / 依据 / 状态 |
| 名称列 | 过窄，折 3~4 行 | 加宽到 120px 单行 |
| 依据列 | 每行“⌖ 图纸 / WL1/2”文字 | 只放 ⌖ 图标，悬停显示回路号，点击定位 |
| 状态列 | 每行“已对齐” | 正常留空；改过：格子左上色角 ◤ + 状态“已改”；存疑：整行淡黄 + “⚠ 存疑” |
| 合计行 | `=COUNTA(B1:B8)·共8种元器件明细`、`=SUM(D1:D8) 20`、“工程量纯量·无单价金额” | `合计 │ 8 种 │ 20 件`；“＋ 添加元器件”移到最后一个空白行 |
| 底部页签 | `Sheet1: 元器件清单 12` 等折行，末尾“+” | `元器件 12 │ 回路 3 │ 待核对 2 │ 修改记录 4`，删“+” |
| 状态栏 | 含“比例 100%” | 删“比例”（与缩放重复） |

## 四、组价页

### 保留
- 树形大表：箱柜行 ▸/▾ 展开元器件行；展开末尾四行构成（元器件小计 / 箱体 / 母排辅材 / 装配人工）
- “设计型号”“报价型号”分列；来源列（价库 / 手填 / 缺价 / 定额 / 联动 / 费率）
- 右侧价格候选面板：价库匹配 / 历史参考价 / 手填录入 + “采用”
- 版本切换 `v1 正泰平替 ▾`（另存 / 对比）

### 修改

| 区域 | 现在 | 改为 |
|---|---|---|
| 顶部参数栏 | 品牌、铜价、人工、利润、税率、成本、总价挤一行，标签竖排；报价总价压住「导出 Excel」 | 拆成两行（见下图）：第一行口径摘要 + [修改口径] + **报价合计**；第二行成本构成 + ⚠缺价 / ✎手填 |
| 口径输入 | 6 个输入框常驻 | 平时只显示摘要；点 [修改口径] 弹出面板编辑，确定后重算 |
| fx 栏 | `=PRICE_LOOKUP(C02, "热继电器 90~130A")` | `I5 │ C02 · 热继电器 90~130A · 单价 · 来源：缺价，可在右侧选价` |
| 表头 | 列字母与中文列名一行一行已分开（OK） | 保持；列名不折行 |
| 子行“安装位置” | 填“主断路器 / 接触回路 / 热保护” | 留空（这不是安装位置） |
| 箱柜行“报价型号” | 斜体“8回路元器件明细已折叠” | 留空；名称后加“（12 项）” |
| 箱柜行“来源” | “汇总” | 留空 |
| 构成行 | 数量“1”落在报价型号列下，各数未对齐 | 严格按列：数量→数量列，单价→单价列，合价→合价列，来源→来源列 |

| 空白行 12~14 | 无作用 | 保留 2 行作为“新增箱柜”输入区，或删除 |
| 状态栏 | 计数 / 求和 / 平均值 | 删“平均值”；写“共 8 箱 / 18 行 │ 求和 ¥269,830.00” |
