## 本轮做过的机械检查

- `index.html` 共 328 个 id、94 个按钮（89 个带 id）。
- 89 个按钮 id 中，87 个在 `app.js/region.js` 有绑定；剩余 2 个是登录/注册 Tab，走 `.auth-tab` 类委托绑定。
- 3 个内联 `onclick`（`setBilling`、`setQuotationBrand`、`handleLeadSubmit`）均有实现。
- 旧问题里的 `btnChat`、`btnDownloadTemplate`、`pricingAdoptLocalBtn` 已不存在或已接真实接口。
- 接口实测：8020 端口上传两张真实 DWG，拆量/组价/两种导出均 200；详见 `T11_端到端验收报告.md`。
