# /check-material-name

对工程量清单拆解出的材料名称逐条做合法性校验。基于铁建 21,300 + 中建 2,667 + 中建八局 3,760 共 24,499 个真实材料名的统计规律，输出每条材料的问题标记和修正建议。

## 使用方式

```
/check-material-name                          # 校验最近一次拆解输出的全部材料
/check-material-name <材料名>                  # 校验单个材料名
/check-material-name <json文件路径>            # 校验 JSON 文件中的材料列表
/check-material-name --strict                 # 严格模式，所有可疑项都标记 review
```

## 何时触发

- Stage4 材料规范化完成后自动触发
- 用户在流水线结果中看到可疑材料名时手动调用
- 批量导入外部清单数据后做质量检查

## 校验规则（按优先级执行）

### R0：名称/规格分离检查（最高优先级）

材料名称和规格型号必须是两个独立字段。材料名是**产品名词短语**，规格是**纯技术参数**。

```
✅ 材料名=薄钢板, spec=冷轧08 0.5mm
❌ 材料名=冷轧08薄钢板0.5mm（规格混入名称）
❌ 材料名=桥架及其配件,结构类型:槽式（KV格式应在spec字段）
```

检查方法：
1. 名称中是否包含尺寸值（`\d+×\d+mm`、`DN\d+`、`Φ\d+`）
2. 名称中是否包含强度等级（`C\d+`、`HRB\d+`、`Q\d+`）
3. 名称中是否包含逗号分隔的 KV 对
4. 去掉疑似规格部分后，名称是否仍然完整

### R1：名称必须是可采购的物理实体

检查方法：能否回答"这是买什么的？" → 能 → 合法。

```
✅ 预拌混凝土、热轧带肋钢筋、SBS改性沥青防水卷材、断桥铝合金窗
❌ 混凝土浇筑、钢筋绑扎、防水施工（工序描述）
❌ 人工费、运输费、管理费（费用项）
❌ 详见设计图纸、参照规范（引用词）
```

### R2：名称长度约束

| 字数 | 判定 | 处理 |
|------|------|------|
| 1字 | 不合法 | **拒绝** — 无法识别为何物 |
| 2字 | 可疑 | 标记 review，需品类上下文确认 |
| 3-4字 | 合法(L1) | 直接使用 |
| 5-8字 | 合法(L2) | 最常用区间 |
| 9-15字 | 合法(L3) | 允许，验证是否可简化 |
| 16字+ | 过度描述 | **标记 review** — 检查是否有规格混入 |

### R3：名称后缀必须落入合法集合

合法后缀（来自三家数据高频统计）：

```
电缆 电线 钢管 钢板 接头 三通 弯头 法兰 直接
砂浆 混凝土 涂料 卷材 止水带 保温板 砌块 门窗 玻璃
螺栓 螺母 垫圈 焊条 密封圈 垫片 支架 预埋件 连接件
设备 装置 系统 机组 总成 配件 开关 阀门 水泵 风机
传感器 控制器 变压器 断路器 继电器 过滤器 检测仪
```

不以这些后缀结尾 → `confidence=low`, `needs_review=true`

### R4：名称不得包含动作词

禁止的动作词：
```
新增 拆除 安装 绑扎 浇筑 砌筑 抹灰 喷涂 铺设 粘贴
拌合 振捣 养护 拆模 压实 组装 调试 接驳 预埋 预留
开挖 回填 夯实 找平 凿毛 切缝 灌浆
```

例外（功能性修饰语，约定俗成）：
- ✅ 自密实混凝土、免拆模板、预制构件

### R5：名称不得是占位词/引用词

禁止：
```
其他、待定、详见设计、详见、暂定、参照图纸、由厂家提供
配套XX、随设备XX、自报、报价、投标
```

### R6：五级命名结构分类

对每个材料名判定层级：

```
L1 纯材料名 (3-4字): 薄钢板、不锈钢管、复合模板
L2 特性+材料 (5-8字): 热轧带肋钢筋、聚合物水泥防水涂料
L3 用途+材料 (6-12字): 桥梁用钢板、流体输送用无缝钢管
L4 品牌/型号+材料: JDG管、KBG管、PVC止水带
L5 系统/装置 (>6字): 全热交换器系统、消火栓系统
```

L5 系统级名称必须尝试拆解为子材料，不可直接当材料名输出。

### R7：修饰词不超过 3 层

标准顺序：`[用途] + [工艺/牌号] + [材质] + [形状] + [核心名词]`

超过 3 层修饰词 → 规格参数混入名称，需拆分。

### R8：费用/服务项识别

名称包含以下后缀 → 标记为费用项，不是材料：
```
费（除"服务器"外）、工资、酬金
```

特别留意中建格式的：`垃圾清运费用、混凝土费用、料具维修费、加工费`

### R9：来源置信度规则

| 来源标记 | confidence | needs_review |
|----------|-----------|--------------|
| `both_verified`（铁建+中建都有） | high | false |
| `tj_verified`（仅铁建） | medium | false |
| `zj_verified`（仅中建） | medium | false |
| `ai_inferred`（AI推断，三家均无） | low | true |

`ai_inferred` 不可自动通过 Stage6 门禁。

## 执行步骤

1. 读取待校验的材料列表（从参数、文件或最近上下文）
2. 对每条材料逐条执行 R0→R9 检查
3. 输出每条材料的校验 JSON
4. 若多条材料（≥3），额外输出汇总报告
5. 标记严重阻塞项：R0 失败、R1 失败、R5 命中 — 这三项**必须修复**，不可进入 Stage6
