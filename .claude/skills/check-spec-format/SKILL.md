# /check-spec-format

对材料规格型号字段做格式校验和自动归类。识别规格属于六种格式中的哪一种，检测常见错误（名称混入、参数无序、引用词），按标准键名做规范化映射。

## 使用方式

```
/check-spec-format <材料名> <规格>              # 校验单个 name+spec 对
/check-spec-format <json文件路径>               # 批量校验
/check-spec-format --fix <材料名> <规格>        # 校验并自动修正
```

## 何时触发

- `/check-material-name` 校验出 R0 问题（名称/规格未分离）后
- Stage4 材料规范化输出后逐条检查
- 中建格式输入（名称和规格混在一起）的批量预处理

---

## 校验规则

### S0：规格字段禁止包含材料名（最高优先级）

规格是纯技术参数。去除规格中每个参数后，材料名不应受影响。

```
✅ material_name=预拌混凝土, spec=C30 泵送
❌ material_name=预拌混凝土, spec=预拌混凝土C30（材料名重复）
❌ material_name=矩形钢管, spec=矩形钢管100×50mm（名称重复）
```

### S1：六种格式自动识别

对规格值做格式匹配，确定其归属类型：

| 格式 | 匹配特征 | 典型值 | 适用品类 |
|------|---------|--------|----------|
| F1 强度/牌号型 | `C\d+`、`HRB\d+`、`Q\d+B`、`MU\d+`、`M\d+` | C30、HRB400E、Q235B | 混凝土、钢筋、钢材、砌体、砂浆 |
| F2 尺寸型 | `\d+×\d+mm`、`DN\d+`、`φ\d+`、`\d+mm` | 100×50×3mm、DN100 | 管材、型材、板材 |
| F3 型号编码型 | 大写字母+数字组合 | YJV-4×25+1×16、JDG25 | 电缆、管线 |
| F4 公称参数型 | `DN\d+\s*PN\d+` | DN100 PN16 | 阀门、管件 |
| F5 复合描述型 | 含多类型参数混排 | Q235B 800×800mm 45°焊接 | 加工件、非标件 |
| F6 厚度/面积型 | 纯厚度/面积值 | 3mm、50mm、1m×20m | 卷材、板材、保温板 |

**判定逻辑**：按 F1→F4 依次匹配，都不命中但含多个独立参数则归为 F5，仅厚度值归为 F6。

### S2：参数拆分与排序

规格字段中的多个参数必须用空格分隔，且按标准顺序排列：

```
F1 顺序: [牌号] [直径/粒径范围] [附加参数]
      例: HRB400E Φ10-Φ25  → ✅
      反: Φ10-Φ25 HRB400E  → ❌ 顺序错误

F2 顺序: [截面尺寸] [壁厚] [长度]
      例: 100×50×3mm       → ✅

F4 顺序: [公称直径] [公称压力]
      例: DN100 PN16       → ✅
```

### S3：中建 KV 格式解析

输入为 `材料名,key1:value1,key2:value2,...` 格式时：

**解析步骤**：
1. 以第一个逗号为界切分名称与规格串
2. 后继逗号为 KV 分隔符，按 `key:value` 拆解
3. 用标准键名表做规范化映射

**中建键 → 标准键映射**：
```
品种 → 类型          材质 → 牌号          公称直径 → 公称直径
种类 → 类型          规格 → 截面尺寸      型号 → 型号编码
公称压力 → 公称压力   厚度 → 厚度         颜色 → 颜色
结构类型 → 结构类型   连接方式 → 连接方式  驱动方式 → 驱动方式
```

### S4：标准规格键名库

校验 spec 中使用的键名是否在标准集合中：

**尺寸参数**：公称直径、外径、内径、截面尺寸、壁厚、厚度、长度、宽度、高度

**力学参数**：强度等级、钢筋牌号、砌体强度、砂浆强度、钢材牌号、不锈钢牌号、螺栓等级

**电气参数**：额定电压、芯数及标称截面、阻燃等级

**压力参数**：公称压力、工作压力

**性能参数**：导热系数、密度、燃烧性能、防水等级、耐火极限

### S5：禁止事项

规格字段中**不得出现**：
```
❌ 产品名词（重复材料名）
❌ 详见设计、参照图纸（引用词）
❌ 由厂家提供、待定（放弃型占位词；真正的"待定"用 pending 标记）
❌ 其他参数详见XXX
❌ 投标、自报、报价（投标用语）
```

## 执行步骤

1. 读取材料名+规格（从参数或文件）
2. 执行 S0 检查（规格是否含材料名）
3. 执行 S1 格式识别（六种格式归类）
4. 如有中建 KV 格式，执行 S3 解析
5. 执行 S2 参数排序检查
6. 执行 S4 标准键名校验
7. 执行 S5 禁止事项检查
8. 输出标准化 spec 和校验 JSON
9. 多条材料时输出汇总
