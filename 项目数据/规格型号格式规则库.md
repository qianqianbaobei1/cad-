# 规格型号格式规则库

> **用途**: 约束AI在BOQ清单拆解时正确分离和格式化规格型号字段。
> **数据来源**: T3标准物料库(330条) + 项目默认值库规格字段统计。
> **版本**: v1.0.0 | 生成日期 2026-05-16

---

## 核心原则

### 规则S0：规格是纯技术参数，名称是产品名词

| 字段 | 包含内容 | 禁止内容 |
|------|---------|----------|
| **material_name** | 产品名词短语 | 牌号、尺寸、强度、厚度、压力、电压、颜色 |
| **spec** | 技术参数 | 产品名称、动作描述、费用说明 |

## 一、规格型号六种基本格式

### 格式1：强度/牌号型（混凝土、钢筋、钢材）

```
模式: [强度等级/牌号] [可选: 附加参数]
示例:
  C30                        → 预拌混凝土 C30
  C30 泵送                    → 预拌混凝土 C30 泵送
  HRB400E Φ10-Φ25            → 热轧带肋钢筋 HRB400E Φ10-Φ25
  Q235B                       → 热轧H型钢 Q235B
  HPB300 Φ6-Φ12              → 热轧光圆钢筋 HPB300 Φ6-Φ12
  MU10                        → 烧结普通砖 MU10
  M10                         → 干混砌筑砂浆 M10
  DM M10                      → 干混砌筑砂浆 DM M10
```

**提取规则**: 强度/牌号是规格的核心值，必须提取。附加参数（泵送、坍落度）用空格分隔。

### 格式2：尺寸型（管材、型材、板材）

```
模式: [截面尺寸] [可选: 壁厚] [可选: 长度]
示例:
  100×50×3mm                 → 矩形钢管
  DN100                       → 钢管
  100×50×5×7mm               → 热轧H型钢
  φ20×2.5mm                   → 焊接钢管
  0.5mm                       → 薄钢板
  3000mm                      → 薄钢板 (长度)
  150×150mm                   → 复合木模板
```

**提取规则**: 尺寸是规格的核心值。`DNxxx` 是公称直径，`φxx` 是外径。

### 格式3：型号编码型（电缆、管线）

```
模式: [型号前缀] [截面/芯数]
示例:
  YJV-4×25+1×16              → 电力电缆
  JDG25                       → JDG管
  ZR-YJV-0.6/1kV 4×25+1×16   → 电力电缆
  NH-RVS-2×1.5                → 耐火铜芯聚氯乙烯绝缘双绞软电缆
```

**提取规则**: 型号编码整体作为规格。不得把编码拆解为材料名。

### 格式4：公称参数型（阀门、管件）

```
模式: [公称直径] [公称压力]
示例:
  DN100 PN16                  → 法兰闸阀
  DN50 PN10                   → 止回阀
  DN25                        → 球阀
```

### 格式5：复合描述型（加工件、非标件）

```
模式: [材质] [尺寸] [工艺] [标准]
示例:
  Q235B 800×800mm 45°焊接     → 钢平台加工件
  304不锈钢 200×300mm 镜面抛光 → 不锈钢饰面板
```

### 格式6：厚度/面积型（板材、卷材）

```
模式: [厚度] [宽度] [长度]
示例:
  3mm                         → SBS改性沥青防水卷材
  0.15mm 1m×20m              → PE防水膜
  50mm                        → 岩棉保温板
```

## 二、规格参数标准化键名

当规格需要拆分为键值对时，使用以下标准键名：

### 尺寸参数
```
公称直径: DN100, DN50, φ25
外径/内径: φ20×2.5mm
截面尺寸: 100×50mm, 100×50×3mm
壁厚: 3mm, 2.5mm
厚度: 0.5mm, 3mm, 50mm
长度: 3000mm, 6m
宽度: 1000mm, 1200mm
高度: 60mm, 80mm
```

### 力学参数
```
强度等级: C30, C25, C35, C40, C50
钢筋牌号: HRB400, HRB400E, HRB500, HPB300
砌体强度: MU10, MU15, MU20
砂浆强度: M5, M7.5, M10
钢材牌号: Q235B, Q355B, Q345B
不锈钢牌号: 304, 316, 316L, 201
螺栓等级: 4.8级, 8.8级, 10.9级
```

### 电气参数
```
额定电压: 0.6/1kV, 10kV, 380V, 220V
芯数/截面: 4×25+1×16, 3×2.5, 5×10
阻燃等级: ZR, NH, WDZ
```

### 压力参数
```
公称压力: PN10, PN16, PN25, PN40
工作压力: 1.6MPa, 2.5MPa
```

### 性能参数
```
导热系数: ≤0.040W/(m·K), ≤0.060W/(m·K)
密度: 200kg/m³, 600kg/m³
燃烧性能: A级, B1级, B2级
防水等级: I级, II级
```

## 三、中建KV格式解析规则

中建系统的规格内嵌在物料名称中：`物料名称,key1:value1,key2:value2,...`

### 解析步骤
1. 以**第一个逗号**为界，之前为材料名，之后为规格串
2. 按 `key:value` 拆分每个规格对
3. 用标准键名做规范化映射

### 常见中建规格键 → 标准键映射
```
品种 → 类型
材质 → 牌号/材质
公称直径 → 公称直径
种类 → 类型
公称压力 → 公称压力
规格 → 截面尺寸
型号 → 型号编码
厚度 → 厚度
颜色 → 颜色
结构类型 → 结构类型
连接方式 → 连接方式
驱动方式 → 驱动方式
```

## 四、规格字段输出格式

### 规则S1：空格分隔，参数有序
```
正确: C30 泵送 坍落度160-200mm
错误: 泵送C30坍落度160-200mm
```

### 规则S2：复合参数按「主参数+修饰」排列
```
正确: HRB400E Φ10-Φ25
顺序: 牌号 → 直径范围
```

### 规则S3：禁止在规格字段中出现材料名
```
正确: material_name=预拌混凝土, spec=C30
错误: material_name=预拌混凝土, spec=预拌混凝土C30
```

### 规则S4：未确定的参数留空或标记 pending
```
正确: spec=C30 泵送
      spec=待定 (不确定时)
      spec=C30 (仅知道强度时)
错误: spec=C30 泵送 其他参数详见设计
```

## 五、常见错误与纠正

### 错误1：强度/牌号留在材料名中
```
❌ material_name=C30预拌混凝土
✅ material_name=预拌混凝土, spec=C30
```

### 错误2：尺寸混入名称
```
❌ material_name=100×50矩形钢管
✅ material_name=矩形钢管, spec=100×50mm
```

### 错误3：厚度混入名称
```
❌ material_name=3mm厚SBS防水卷材
✅ material_name=SBS改性沥青防水卷材, spec=3mm
```

### 错误4：把材料名重复写入规格
```
❌ material_name=热轧带肋钢筋, spec=热轧带肋钢筋HRB400
✅ material_name=热轧带肋钢筋, spec=HRB400
```

### 错误5：多规格参数无序堆砌
```
❌ spec=100mm Q235B 壁厚5mm 热轧
✅ spec=Q235B 100×100×5mm
```

## 六、AI输出校验清单

对每个输出材料，检查规格字段是否：
```
□ 只包含技术参数（不含产品名）
□ 参数用空格分隔，顺序合理
□ 主参数在前（强度/直径/型号），修饰在后
□ 不含"详见"、"参照"等引用词
□ 不确定的参数留空/标记 pending，不编造
□ 格式匹配该品类对应的六种格式之一
```
